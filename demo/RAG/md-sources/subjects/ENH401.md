# ENH401 - Business English for Hospitality - Upper Intermediate_Tiếng Anh Chuyên ngành Khách sạn - Du lịch Trung cấp 2


## Course Information - ENH401

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45 contact hours (60 sessions) + 1.6 hours final exam + 103.4 hours self-study
- **Pre-Requisite**: ENH301
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - ENH401
1. Objectives: • build confidence in professional skills such as dealing with enquiries, marketing destinations, offering advice, negotiating, writing emails and speaking to groups • develop language awareness through an integrated grammar and skills syllabus • acquire the specialized vocabulary needed by tourism professionals • practise language skills in realistic Case studies that reflect issues in the tourist industry today. 2. Description: English for International Tourism is a three-level series designed to meet the English language needs of professionals working in the tourism industry and students of tourism in further education. 3. Teaching method: lecture and seminar format 4. Assessment scheme: On-going assessment: 50% Final examination: 50 % Completion Criteria: Every on-going assessment component >0, each part of the final exam must be >0, Final Exam Score >=4/10 & Final Result >=5/10.

### Student Tasks - ENH401
- Student must attend at least 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises, assignments given by the instructor in class or at home and submit on time - Use laptop in class only for learning purpose

## Course Learning Outcomes (CLOs) - ENH401

- **CLO1**: Use continuous aspect Apply vocabulary to describe tourist motivations and visuals Apply professional skills when using visuals Tailor a package
- **CLO2**: Use countable and uncountable nouns Use vocabulary in advertising and publicity, web words, collocations Apply professional skills when maintaining a website Create and improve a media profile
- **CLO3**: Make predictions Use vocabulary for brands Apply professional skills when creating a business plan Know how to invest in a hotel
- **CLO4**: Use reporting verbs Use verb + noun collocations; use vocabulary related to tourism and community Apply professional skills when chairing a meeting Develop an eco-resort
- **CLO5**: Use grammar to talk about the past Use vocabulary to describing a heritage site, architecture, guiding expressions Apply professional skills when working as a tour guide Design a museum exhibition
- **CLO6**: Use conditional forms to describe hypothetical situations Discuss different kinds of large event by using collocations with event Apply professional skills of understanding contracts Make a festival profitable
- **CLO7**: Use dependent prepositions Use vocabulary concerned with remuneration; adjectives describing personality Apply professional skills in interviews Recruit the right person
- **CLO8**: Use relative clauses Use vocabulary for food and cooking Apply professional skills when giving feedback Plan a new itinerary
- **CLO9**: Use modal verbs UsevVocabulary to describe disasters, adventure sports Apply professional skills when dealing with crises
