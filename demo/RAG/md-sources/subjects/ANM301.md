### Description - ANM301
This course will prepare you: This course covers the fundamentals of working in CG (Computer Graphic) with Maya. It’s only a starting point, though. As with any artistic pursuit, CG is a lifelong process of learning. With what you learn in this course forming a solid foundation, you can continue exploring all the complex, interesting facets of creating CG imagery Teaching methods: - Student is the center, practice combined with theory - Help students have a self-study method - Presentation method combined with group working method - Teachers are instructors, organizing activities - The result is a combination of teacher and student evaluation

## Schedule - ANM301

Total sessions: 10

**Session 1**: 'Getting Started with Maya Working with basic tools
  CLO: LO1 | Tasks: Student: Discussion. Teacher: 1 - Introduction to Autodesk Maya 2 - The Maya user interface 3 - Managing Scenes, Files, and Projects 4 - Creating primitive objects, moving, rotating, scaling object 5 - Shortcuts to manipulate the workspace, object 6 - Components and attributes 7- Select objects and components 8- Transform, group and parent objects 9- Snap and align objects 10- Operate keyboard shortcuts | Materials: Textbooks, PPT presentation, and other resources
**Session 2**: Draw NURBS curves
  CLO: LO2 | Tasks: Student: Discussion, Exercises. Teacher: 1. CV Curve Tool Options 2. EP Curve Tool Options 3. Make a curve or surface open or closed 4. Create arcs 5. Reshape a curve or surface manually 6. Edit NURBS curves and surfaces | Materials: Textbooks, workbooks, PPT presentation, and other resources
**Session 3**: Working with NURBS Surfaces
  CLO: LO3 | Tasks: Student: Discussion, Exercises. Teacher: 1- Revolve 2- Loft 3- Bevel 4- Boundary 5- Extrude 6- Put illustrator file into Maya | Materials: Textbooks, workbooks, PPT presentation, and other resources
**Session 4**: Creating and Editing polygon objects
  CLO: LO4 | Tasks: Studnet: Discussion, Exercises. Teacher: 1. Analysis Grid (Grid runs rough blocks, the motion, the standard for animated mesh.) 2. Analyze how to implement Modeling (Modeling 1 block, Modeling partially combined, Retopolygy.) 3- Operate with select vertex, edge, face. 4- Work with Select menu: Similiar, Grow, Shrink. 5- Work with Edit Mesh menu: - Add Divisions - Bevel - Connect - Detach - Extrude - Duplicate - Chamfer | Materials: Textbooks, workbooks, PPT presentation, and other resources
**Session 5**: Human face topology
  CLO: LO5 | Tasks: Student: Discussion, Exercises. Teacher: 1- Faster operation with the same command on the command panel 2. Modeling with some command group - Mesh: combine, seprate ... - components: Extrude, Bridge, ... - Tool: Multicut, target weld, connect ... 3- Asymmetry of the face 4- Block out the eye 5- Block out the mouth and the chin 6- Build up the eye region 7. Some techniques for Modeling (Rounds, keeping the corner, smoothing the surface, connecting surfaces, the error checking, balance points, reverse normal ...) | Materials: Textbooks, workbooks, PPT presentation, and other resources
**Session 6**: Human body topology
  CLO: LO6 | Tasks: Student: Discussion, Exercises. Teacher: 1. Create the nose 2. Create the ear 3. Body topology 4. Adding the neck and the back of the head 5. Create the skin flow of the eyes 6. Connect the head to the body 7. Rediting the proportions 8. Reworking the topology 9. Use brush preset 10..Create custom brushes 11. Sculpt Tools 12. Paint in 3D objects | Materials: Textbooks, workbooks, PPT presentation, and other resources
**Session 7**: Assign Materials and textures part 01
  CLO: LO7 | Tasks: Student: Discussion, Exercises. Teacher: Create and assign a material 1- Use hypershape 2- Apply materials 3- Work with material 4- Work with texture and position texture 5- Use displacement map | Materials: Textbooks, workbooks, PPT presentation, and other resources
**Session 8**: Assign Materials and textures part 02
  CLO: LO8 | Tasks: Student: Discussion, Exercises. Teacher: 1- Mapping UVs 2- Planar UV mapping 3- Edit Uvs 4. Paint in 2D | Materials: Textbooks, workbooks, PPT presentation, and other resources
**Session 9**: Use camera and light
  CLO: LO9 | Tasks: Student: Discussion, Exercises. Teacher: 1- Scene Setup 2- Working with camera 3- Light Settings 4- Shading | Materials: Textbooks, workbooks, PPT presentation, and other resources
**Session 10**: Rendering a scence
  CLO: LO10 | Tasks: Student: Discussion, Exercises. Teacher: 1- Rendering a scene 2- Lights, shadows, and cameras 3- Camera Depth of Field 4- Rendering | Materials: Textbooks, workbooks, PPT presentation, and other resources
