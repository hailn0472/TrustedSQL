### Description - NWC202
Building on the successful top-down approach, the course of Computer Networking is implemented with an early emphasis on application-layer paradigms and application programming interfaces, encouraging a hands-on experience with protocols and networking concepts.

### Student Tasks - NWC202
- Students must attend more than 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to the FU CMS at http://cms.fpt.edu.vn for up-to-date course information

## Course Learning Outcomes (CLOs) - NWC202

- **CLO1**: General knowledge of computer networking
- **CLO2**: Details of architecture of OSI and TCP/IP model,
- **CLO3**: Protocols, services of each layer
- **CLO4**: Main problems of Networking
- **CLO5**: Using basic shell command in Linux system fluently
- **CLO6**: Fundamental of shell, C language on Linux
- **CLO7**: Main problems of Network through some simulative exercises
- **CLO8**: Information searching, reading and selection skills
- **CLO9**: Working in group, documention and presentation skills
