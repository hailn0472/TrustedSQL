### Description - CSR301
This course is designed based on the Certificate of Cloud Security Knowledge (CCSK) course. The Cloud Security course is designed for Cisco Networking Academy® students who will learn the fundamentals of cloud computing and prepare for the Certificate of Cloud Security Knowledge (CCSK). The CCSK certificate is widely recognized as the standard of expertise for cloud security and gives you a cohesive and vendor-neutral understanding of how to secure data in the cloud.

## Course Learning Outcomes (CLOs) - CSR301

- **CLO1**: Explain the employment opportunities by filling the skills-gap for cloud-certified professionals.
- **CLO2**: Explain in-depth understanding of the full capabilities of cloud computing.
- **CLO3**: Evaluate to effectively develop a holistic cloud security program relative to globally accepted standards
- **CLO4**: Evaluate best practices for Identity and Access Management (IAM), cloud incident response, application security, data encryption, Security as a Service, and securing emerging technologies.
- **CLO5**: Apply security threats and best practices for securing the cloud
- **CLO6**: Explain the competency in key cloud security issues through an organization that specializes in cloud research.
- **CLO7**: Demonstrate for students technical knowledge, skills, and abilities to effectively use controls tailored to the cloud.
- **CLO8**: Understand how to establish a baseline of security best practices when dealing with a broad array of responsibilities, from cloud governance to configuring technical security controls.
- **CLO9**: Recognize the behavior-based approach to cloud security and interest in cloud security.
- **CLO10**: Understand legal and ethical issues in cloud security.
- **CLO11**: Explain the opportunities for pursuing an education and a career in cloud security.
- **CLO12**: Evaluate cloud security risks in an industry sector
- **CLO13**: Use industry-standard models to explain security requirements in Cloud computing.
