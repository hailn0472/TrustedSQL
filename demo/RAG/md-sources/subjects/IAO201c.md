### Description - IAO201c
This course will introduce fundamental modern information and system protection technology and methods, develop a lifelong passion and appreciation for cyber security.

### Student Tasks - IAO201c
Student must get the certification of Introduction to Cyber Security Specialization specialization specialization from Coursera to be accepted to the final examination.

### Tools - IAO201c
- Internet

## Course Learning Outcomes (CLOs) - IAO201c

- **CLO1**: Explain underlying concepts related to common cyber security threats, vulnerabilities, and risks.
- **CLO2**: Explain basics of cyber defense starting with foundational models such as Bell-LaPadula and information flow frameworks.
- **CLO3**: Explain real-time cyber security techniques and methods in the context of the TCP/IP protocol suites.
- **CLO4**: Summary advanced and current topics in cyber security, many of which are especially relevant in modern enterprise and infrastructure settings.
