# LAB221 - Desktop Java Lab


## Course Information - LAB221

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Class hours: 45h ( 30 slots, 1 slot = 1.5H)
Home study: 90h
- **Pre-Requisite**: PRJ311

### Description - LAB221
This course focuses on basic problems related to Java desktop programming skills. Students are required to implement all assignments by him/her self in lab rooms. Each assignment must be completed continuosly in the defined time.

### Student Tasks - LAB221
- Students must attend at least 80% of contact slots in order to be accepted to the final results. - Students are responsible to conform to Lab Room Regulations - Use desktop computers only in lab room for learning purposes - Promptly access to the FU CMS at http://cms.fpt.edu.vn for up-to-date course information

### Tools - LAB221
NetBean 8.0.2 CheckStyle plugin for netbeans JAVA DOC JDK8 Tomcat Apache 8 Microsoft Excel 2007 or above Microsoft Word 2007 or above Microsoft Powerpoint 2007 or above Microsoft Windows XP or above

## Course Learning Outcomes (CLOs) - LAB221

- **CLO1**: Proficency in Java skills required in PRJ311 Course
- **CLO2**: Be able to Independently complete small-size assignments
- **CLO3**: Be able to debug code using common tools
