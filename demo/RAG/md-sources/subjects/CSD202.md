### Description - CSD202
This course introduce the fundamental concepts of data structures and the algorithms that proceed from them. Such data structures and algorithms as being implemented in C++ are also given in this course.  Topics include the basics of algorithmic analysis, fundamental data structures (including stacks, queues, linked lists, hash tables, trees), recursion, and some important applications of these data stuctures and algorithms.
