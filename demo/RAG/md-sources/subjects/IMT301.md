# IMT301 - Image Processing Technology_Công nghệ xử lý ảnh


## Course Information - IMT301

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 1h final exam + 104h self-study
- **Pre-Requisite**: MAD101, MAS291, CSI104
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - IMT301
Upon finishing the course, students must acquire: 1. the following knowledge: (ABET a1) • Fundamental concepts of Digital Image Processing. • Basic image processing operation. 2. the following skills: (ABET a2) • Image analysis algorithms. • Current applications in the field of digital image processing. • Fundamental concepts and basic functions in Tensorflow. • Using Tensorflow in image processing

### Student Tasks - IMT301
- Students must attend more than 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises given by instructor in class or at home and submit on time - Use laptop in the class for learning purpose only - Constantly follow announcements on intranet/CMS at http://cms.fpt.edu.vn for up-to-date course information regarding assignment submission and feedback on assignments

### Tools - IMT301
Tensorflow

## Course Learning Outcomes (CLOs) - IMT301

- **CLO1**: Explain how digital images are represented and manipulated in a computer, including reading and writing from storage, and displaying.
- **CLO2**: Write a program which implements fundamental image processing algorithms.
- **CLO3**: Be conversant with the mathematical description of image processing techniques and know how to go from the equations to code.
- **CLO4**: An ability to apply knowledge and identify the computing requirements appropriate for its solution.
- **CLO5**: An ability to design, implement and evaluate a computer-based system, process, component or program to meet desired needs.
- **CLO6**: An ability to apply mathematical foundations, algorithmic principles and computer science theory to the modeling and design of computer based systems in the way that demonstrates comprehension of the tradeoffs involved in design choices.
- **CLO7**: An ability to use all the main functions of Tensorflow and understand how to apply them to process a problem in image processing.
- **CLO8**: An ability to understand the advantages and disvantages of Tensorflow in comparison with other image processing's frameworks (OpenCV, Keras, etc...).
