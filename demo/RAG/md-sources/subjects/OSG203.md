# OSG203 - Operating System_Hệ điều hành


## Course Information - OSG203

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 1h final exam + 104h self-study
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - OSG203
At the end of this course, students will be able to: 1.Background Knowledge: (ABET e) - Understand the role and functions of an operating system. - Grasp important OS concepts such as kernels, file systems, and process management. - Comprehend the mechanisms of operating systems, including memory hierarchy and CPU roles. - Identify and analyze main problems and challenges in operating systems. 2.Practical Skills: (ABET k) - Use basic and advanced shell commands in a Linux system fluently. - Develop proficiency in shell scripting on Linux. - Address and solve key operating system problems through practical exercises and simulations. 3.Information Searching, Reading, and Selection Skills: (ABET i) - Efficiently search for, read, and select relevant information related to operating systems and Linux. 4.Teamwork, Documentation, and Presentation Skills: (ABET g) - Work effectively in groups to complete projects. - Document and present findings and solutions clearly and professionally.

### Student Tasks - OSG203
- Students must attend at least 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to the FU LMS https://flm.fpt.edu.vn/ for up-to-date course information

### Tools - OSG203
- Internet - Linux (CentOS, Ubuntu) operating system server and/or client

## Course Learning Outcomes (CLOs) - OSG203

- **CLO1**: Grasp the core concepts of operating systems, including the kernel, process management, memory management, and file systems.
- **CLO2**: Understand how operating systems manage resources within the context of Linux.
- **CLO3**: Utilize the command line to operate and administer the Linux system.
- **CLO4**: Master regular expressions and shell scripting to automate tasks and manage system operations.
- **CLO5**: Develop advanced practical skills in Linux system administration.
- **CLO6**: Learn and implement basic security solutions on Linux systems.
- **CLO7**: Configure and understand TCP/IP networking protocols.
- **CLO8**: Set up and manage services on Linux systems.
- **CLO9**: Use AI, standard tools and techniques to manage, maintain, and troubleshoot Linux systems.
