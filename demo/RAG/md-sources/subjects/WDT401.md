- **Credits**: 3

- **Min Avg Mark To Pass**: 5

### Description - WDT401
This course aims to provide technical knowledge and skills for student. Student will learn about web technologies such as HTML, CSS and Javascript. They have to practice to create website from the simple to a complex client-size or front-end web application. This is the advanced course of Web Design course, so student will continue their work in the end of the first course, and make an empirical version of last graphical design product in its project by applying web technologies. Beside the technologies, in this course student will learn about web design principles and approaches such as responsive web, and also understand techniques and tools to implement a website in a development processes. After this course, student can completely create a web themes includes images, icons, css(s), html(s) and javascript(s).

### Student Tasks - WDT401
- Attendance >=80% - Actively participate in class activities - Fulfill tasks given by instructor after class - Use their own laptop in class only for learning purpose - Read the textbook in advance - Access the course website (www.fap.fpt.edu.vn) for up-to-date information and material of the course, for online supports from teachers and other students and for practicing and assessment. - Computer with graphic softwares for creating website layouts (Photoshop/ Illustrator/ Sketch, ...) and web development tool (Dreamweaver/ Sublime Text, ...) - Complete course's Portfolio with full contents of exercises and submit to the teacher 1 day after the course.

## Course Learning Outcomes (CLOs) - WDT401

- **CLO1**: Define responsive website
- **CLO2**: Develop the static website layouts to HTML pages (front-end phase)
- **CLO3**: Design interaction for the website by using CSS and JavaScript Library (navigation, link HTML pages, gallery slide show, ...)
- **CLO4**: Add media files (video, audio, ...) to the web site
- **CLO5**: Apply Bootstrap to creating responsive, mobile-first web sites
- **CLO6**: Test front-end version of the web site and fix errors
- **CLO7**: Students have a proficient in presentation and teamworks. Having a professional working style.
- **CLO8**: Distinguish different devices' screen resolutions
- **CLO9**: Explain the reasons of using grid systems in web design
- **CLO10**: Apply grid systems to the web site interfaces in order to develop responsive web site
- **CLO11**: List different image formats in web design
- **CLO12**: Select appropriate image formats in web design
- **CLO13**: List basic HTML tags for creating web themes (index page, content page, contact page, ...)
- **CLO14**: List basic CSS for styling web elements (font, paragraph, heading, navigation, link, button, form, ...)
- **CLO15**: Learn Bootstrap framework
