### Description - AIL302
Machine learning is the science of getting computers to act without being explicitly programmed. In the past decade, machine learning has given us self-driving cars, practical speech recognition, effective web search, and a vastly improved understanding of the human genome. Machine learning is so pervasive today that you probably use it dozens of times a day without knowing it. Many researchers also think it is the best way to make progress towards human-level AI.  This course provides a broad introduction to machine learning, datamining, and statistical pattern recognition. Topics include: (i) Supervised learning (parametric/non-parametric algorithms, support vector machines, kernels, neural networks). (ii) Unsupervised learning (clustering, dimensionality reduction, recommender systems, deep learning). (iii) Best practices in machine learning (bias/variance theory; innovation process in machine learning and AI). The course will also draw from numerous case studies and applications, so that you'll also learn how to apply learning algorithms to building smart robots (perception, control), text understanding (web search, anti-spam), computer vision, medical informatics, audio, database mining, and other areas.  This course will be implemented through online mode. Students will learn officially the online course "Machine Learning" on Coursera. During the online learning process, students will be guided by teachers-tutors through some offline sessions on the campus, and through emails

## Course Learning Outcomes (CLOs) - AIL302

- **CLO1**: Obtain a deep knowledge about linear regression with one variable:
- **CLO2**: Demonstrate a deep understanding about linear regression model with one variable.
- **CLO3**: Understand and calculate the cost function and gradient descent method for Linear regression with one variable.
- **CLO4**: Demonstrate an understanding about the idea and intuitions behind Support Vector Machines (SVM), for classification and being able to use it in practice.
- **CLO5**: Demonstrate a understanding about the k-Means algorithm for clustering unlabeled data points.
- **CLO6**: Demonstrate a deep understanding about Principal Components Analysis, and use it for data compression to speed up learning algorithms as well as for visualizations of complex datasets.
- **CLO7**: Be able to model a dataset using a Gaussian distribution, and use this model for anomaly detection.
- **CLO8**: Be able to perfom the recommender algorithms such as the collaborative filtering algorithm and low-rank matrix factorization.
- **CLO9**: Apply the machine learning algorithms with large datasets.
- **CLO10**: Master online studying skill and be ready for life long learning.
- **CLO11**: Be able to implement the learning algorithms in practice using Octave or MATLAB
- **CLO12**: Obtain a deep knowledge about linear regression model with multiple variables
- **CLO13**: Demonstrate a deep understanding about linear regression model with multiple variables
- **CLO14**: Understand and calculate the cost function and gradient descent method for Linear regression with multiple variables
- **CLO15**: Being able to classify data into discrete outcomes using logistic regression method. Apply cost function for Logistic regression
- **CLO16**: Being able to prevent models from overfitting the training data by using regularization.
- **CLO17**: Demonstrate an understanding about neural networks: what neural networks are, what representations of neural network models.
- **CLO18**: Demonstrate an understanding about the backpropagation algorithm for training neural networks.
- **CLO19**: Being able to evaluate performance of the learned models
- **CLO20**: Demonstrate a understanding about the performance of a machine learning system with multiple parts, and being able to deal with skewed data.
