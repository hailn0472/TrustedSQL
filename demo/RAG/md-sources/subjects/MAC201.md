### Description - MAC201
This course provides an introduction to ordinary differential equations with applications. Topics include first-order, linear higher-order, and systems of differential equations; series solutions; Laplace transforms; and stability of nonlinear differential equations. Upon completion, students should be able to use differential equations to model real-life phenomena, solve the equations, and use the solutions to analyze the phenomena.
