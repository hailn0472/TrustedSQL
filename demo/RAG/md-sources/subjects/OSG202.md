# OSG202 - Operating System_Hệ điều hành


## Course Information - OSG202

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 1h final exam + 104h self-study'
- **Min Avg Mark To Pass**: 0
- **Scoring Scale**: 10

### Description - OSG202
At the end of this course, students will be able to perceive: 1) Background knowledge: (ABET e) -The role of operating system, - important OS concepts, - the mechanism of operating system, and - main problems of Operating system. 2) Practice skills: (ABET k) - Using basic shell command in Linux system fluently. - Fundamental of shell, C language on Linux. - Main problems of Operating system through some simulative exercises. 3) Information searching, reading and selection skills (ABET i) 4) Working in group, documenting and presenation skills (ABET g)

### Student Tasks - OSG202
- Students must attend at least 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to the FU LMS https://flm.fpt.edu.vn/ for up-to-date course information

### Tools - OSG202
- Internet - Linux operating system server and/ or desktop - MARIE simulator - AI tools (ChatGPT/Copilot/Gamma…) and other simulation software if deemed appropriate.

## Course Learning Outcomes (CLOs) - OSG202

- **CLO1**: Understand the main concepts of operating system
- **CLO2**: Understand basic C/C++ language on Linux
- **CLO3**: Using AI tools to futher explore the main concepts of OS's components
- **CLO4**: Understand the main concepts of process management
- **CLO5**: Understand the main concepts of memory management
- **CLO6**: Understand the main concepts of file systems
- **CLO7**: Understand the main concepts of I/O systems
- **CLO8**: Understand the main concepts of deadlock
- **CLO9**: Using Linux operating system
- **CLO10**: Using basic shell command in Linux system fluently
- **CLO11**: Understand basic Shell language on Linux
