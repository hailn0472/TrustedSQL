### Description - REL301m
This course helps students understand the concepts of Reinforcement Learning including the space of RL algorithms (Temporal- Difference learning, Monte Carlo, Sarsa, Q-learning, Policy Gradients, Dyna, and more). Students will understand how to formalize these tasks as a Reinforcement Learning problem. Students will learn how RL fits under the broader umbrella of machine learning, and how it complements deep learning, supervised and unsupervised learning. Students can implement a complete RL solution and understand how to apply AI tools to solve real-world problems.

## Course Learning Outcomes (CLOs) - REL301m

- **CLO1**: Understand the concepts of Reinforcement Learning
- **CLO2**: Know how to implement dynamic programming as an efficient solution approach to an industrial control problem
- **CLO3**: Understand several algorithms for estimating value: Temporal-Difference learning, Monte Carlo
- **CLO4**: Undersatnd and implement a model-based approach to RL: Temporal-Difference, Expected Sarsa, Q-learning
- **CLO5**: Understand several approaches that affect approximate value functions: supervised learning, fixed basis, neural network.
- **CLO6**: Understand how function approximation is used to predict and control in Reinforcement Learning
- **CLO7**: Understand and implement an RL solution to a problem step by step: problem formulation, appropriate algorithm selection, implementation, and empirical study into the effectiveness of the solution.
