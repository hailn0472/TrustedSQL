### Description - SAP341
This course covering basis programming with ABAP, high-level programming language developed by SAP, primarily used for building and customizing business applications within the SAP ecosystem. The students will learn from the basis (ABAP's syntax, data types, control structures, object-oriented programming) to advanced concepts (modulization, performance optimization...) of ABAP, ensuring a solid foundation and practical expertise ... Through interactive exercises, and hands-on projects, students will get familiar with developing SAP application in real-world scenarios.

## Course Learning Outcomes (CLOs) - SAP341

- **CLO1**: Understand the fundamental concepts and principles of ABAP programming, including data types, variables, and basic structures.
- **CLO2**: Use the ABAP Worchbench tools to create and maintain programs, function modules, and classes.
- **CLO3**: Use the Open SQL commands to read and write data, fetch and manipulate data from SAP database tables.
- **CLO4**: Apply object-oriented programming concepts, such as classes, objects, inheritance, and polymorphism in ABAP.
- **CLO5**: Understand techniques to build reusable, reliable and efficient programs.
- **CLO6**: Use frameworks, libraries and protocols to create enterprise-ready web applications in an efficient way
- **CLO7**: Apply the learned concepts in real-world programming assignments and projects.
- **CLO8**: Develop professional working style, good teamwork skills and compliance with the production process.
