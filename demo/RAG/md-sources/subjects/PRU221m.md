### Description - PRU221m
This course is a course that builds on the knowledge included in the C# Programming for Unity Game Development Specialization, so the course assumes you have the prerequisite knowledge from the PRU211m. You should make sure you have that knowledge, either by taking those previous courses or from personal experience, before tackling this course. You should make sure you have that knowledge, either by taking those courses or from personal experience, before tackling this course. Throughout this course you'll build on your foundational C# and Unity knowledge by developing more robust games with better object-oriented designs using file input and output, inheritance and polymorphism, event handling and various data structures and design patterns. Data structures and design patterns are both general programming and software architecture topics that span all software, not just games. Although we'll discuss these ideas in the game domain, they also apply if you're writing a web app in ASP.NET, building a tool using WinForms, or any other software you decide to build.

## Course Learning Outcomes (CLOs) - PRU221m

- **CLO1**: Able to use and implement exception handlers
- **CLO2**: Able to complete algorithm analysis and use different data structures in developing games with Unity Games
- **CLO3**: Able to describe the Component pattern and how it relates to the Unity engine
- **CLO4**: Able to describe how the event managers implement the Mediator pattern
- **CLO5**: Able to read and write a text file
- **CLO6**: Able to use and develop inheritance
- **CLO7**: Able to develop game functionality using events and event handlers
- **CLO8**: Able to develop a full menu system in a game
- **CLO9**: Able to build a game that use event manager and event handling.
- **CLO10**: Able to build a game that use a single game audio source for all sound effects.
- **CLO11**: Able to describe how to implement a generic class
- **CLO12**: Able to develop a class that implements an interface
