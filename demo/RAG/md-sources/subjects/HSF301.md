# HSF301 - Hibernate and Spring Framework_Hibernate & Spring Framework


## Course Information - HSF301

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 1h final exam + 85' practical exam + 104h self-study
- **Pre-Requisite**: PRJ301
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - HSF301
Upon completion of this course students shoud: 1. Understand the followings: • Basic concepts of Java FX to build Desktop Application • Basics of Object-Relational Mapping (ORM) with Hibernate and how it simplifies database interactions. • Spring Framework, which provides a comprehensive ecosystem for building enterprise-level applications. • Spring Framework's dependency injection, AOP, and web frameworks to build robust and scalable applications  2. Be able to: • Develop Cross-platform Desktop applications and support for user experience (UI & UX) • Use Hibernate as a powerful ORM tool to map Java objects to database tables. • Use Spring Framework's dependency injection, AOP, and web frameworks to build robust and scalable applications.  3. Be able to work in team and present group's results

### Student Tasks - HSF301
- Students must attend at least 80% of contact sessions in order to be accepted to the final examination. - Student is responsible to do all assigned exercises given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to the https://flm.fpt.edu.vn/ for up-to-date course information

### Tools - HSF301
- Internet - IntelliJ IDEA or Sping Tool 4 for Eclipse/Visual Studio Code - Platform : Java Development Kit 20

## Course Learning Outcomes (CLOs) - HSF301

- **CLO1**: Describe the basics of Object-Relational Mapping (ORM) and how it simplifies database interactions.
- **CLO2**: Create Cross-Platform applications using JavaFX. JavaFX is platform-independent, which means that JavaFX applications (CRUD) can run on different operating systems such as Windows, macOS, and Linux
- **CLO3**: Describe the concepts of Spring Framework and Spring MVC provides a comprehensive programming and configuration model for modern Java-based enterprise applications.
- **CLO4**: Create application with Hibernate and Spring Framework.
- **CLO5**: Develop teamwork skills, communication skills (including presentation skills)
