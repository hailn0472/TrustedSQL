### Description - SWD392
This is a course in concepts and methods for the architectural design of software systems of sufficient size and complexity to require the effort of several people for many months. Fundamental design concepts and design notations are introduced. Several design methods are presented and compared, with examples of their use. Students will undertake a term project working in small groups addressing the design of a relatively complex software system.

## Assessment - SWD392

### Course Project
- Weight: 25.0%
- Completion Criteria: 5
- CLO: All LOs
- Question Type: Option 1: N/A; Option 2 (For Constructivism Approach only): Follow lecturer's proposal
- Note: 1. On-going Assessment: 40%
Students work in a project team of 4-5 members on the assignments as appointed by the teacher
The works are organized by iterations with the contents and assessments as below
(each student is assign to practice full-stack codes on assigned/selected function).
Throughout the process, students are encouraged to use AI tools (e.g., ChatGPT, GitHub Copilot), under the following conditions:
- Must transparently declare AI usage (e.g., what prompt was used, which part was generated by AI).
- Must explain AI-generated output using their own understanding.
a. Evaluation 1 (20%) – Requirement Analysis & Modeling
Create use case descriptions and UML diagrams (static and dynamic models).
AI can assist with modeling, but students must present their reasoning independently.
Required Deliverables: AI prompts (if used), UML diagrams (e.g., PlantUML or Visio), written explanations.
b. Evaluation 2 (20%) – Software Architecture & Design
Design software architecture, decompose into subsystems, object-oriented design, and database schema.
AI can help propose architecture or generate code samples, but students must refine and justify the result.
Required Deliverables: Architecture docs, diagrams, code snippets, explanation of AI-assisted parts.
2. Final Project Presentation: 60%
Each team presents their integrated software product and individual responsibilities.
The individual evaluation includes an additional component for AI usage as follows:
- Integrated Software Product Demostration for Software design (30%): Web API , Web Admin, Mobile App...
- Mastery of assigned works: weighted 20%
- Soft Skills & Working Attitudes: weighted 10%
AI Evaluation Rubric (for individual performance – up to 10 points)
- Understanding of AI Output
- Customization and Enhancement of AI Output
- Transparency (Prompt + AI Use Declaration)
- Effective and Ethical AI Usage

To be selected to the Final Presentation, each student needs:
* All on-going assessments (Evaluation 1 & Evaluation 2) >=5/10
* No cheating during the project progress
