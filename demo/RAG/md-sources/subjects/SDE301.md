### Description - SDE301
This course provides a comprehensive understanding of state-of-the-art engineering practices used in the self-driving car industry. Students will get to interact with real data sets from an autonomous vehicle (AV)―all through hands-on projects using the open source simulator CARLA.  Students will learn from a highly realistic driving environment that features 3D pedestrian modelling and environmental conditions. When students complete the course successfully, they’ll be able to build your own self-driving software stack and be ready to apply for jobs in the autonomous vehicle industry

## Course Learning Outcomes (CLOs) - SDE301

- **CLO1**: Understand the detailed architecture and components of a self-driving car software stack
- **CLO2**: Able to implement methods for static and dynamic object detection, localization and mapping, behaviour and maneuver planning, and vehicle control
- **CLO3**: Able to apply realistic vehicle physics, complete sensor suite: camera, LIDAR, GPS/INS, wheel odometry, depth map, semantic segmentation, object bounding boxes
- **CLO4**: Demonstrate skills in CARLA and build programs with Python
