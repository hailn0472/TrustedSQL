### Description - IAD101b
The course is aim to equip lIn this course, you will become familiar with the industry and the components of an automotive system; overview of automotive software development; overview of automotive programming languages; operating system and car communication network; and the field's standards. Through this course, you get a complete picture of automotive application development and job opportunities in this strongly growing industry.earners to create convenient, fine user interface on auto. Qt is a popular framework to develop UI software application on automotive sysem. The student will learn about Principles of Qt framework; Techniques, tools and skills essentials to build UI with QML; Techniques to link UI in QML with functional logics in C++; How to use Qt framework for techniques in programming like Multithread, multi languages
