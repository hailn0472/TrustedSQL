### Description - PRJ311
The course is composed of 3 parts: Part 1 is for overview of JAVA technology and strengthening the basic knowledge and skills in java programming language such as using multi- threading programming, GUI programming, processing graphics, Java internationalization utilities Part 2 is for developing Java distributed applications Part 3 is for developing Java database applications

### Student Tasks - PRJ311
- Students must attend more than 80% of contact sessions in order to be accepted to the final examination. - Student is responsible to do all exercises given by instructor in class or at home and submit on time - Promptly access to the FU CMS at http://cms.fpt.edu.vn for up-to-date course information

### Tools - PRJ311
• Internet access • JDK 1.8 or higher • JDK 1.8 or higher Documentation • NetBeans 7.x or higher • MS SQL Server 2008 or higher

## Course Learning Outcomes (CLOs) - PRJ311

- **CLO1**: Discuss the concept of concurrency programming and muti-threading application
- **CLO2**: Explain the issue of concurrency programming, thread Synchronization and Wait/Notify mechanism
- **CLO3**: Discuss the role of JFC and Swing and applies the use of swing components to create a GUI application
- **CLO4**: Applies the use of swing layout for designing a window application
- **CLO5**: Applies the event handling for writing event listeners for swing components
- **CLO6**: Explain how to program network application using Socket API and RMI
- **CLO7**: Demonstrates how to display and print 2D graphics in your Java programs
- **CLO8**: Demonstrates the use of JDBC to execute common SQL statements, and perform other objectives common to database applications.
- **CLO9**: Demonstrates how to internationalize Java applications
