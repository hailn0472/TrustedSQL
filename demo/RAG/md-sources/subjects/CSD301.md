# CSD301 - Advanced Algorithms_Giải thuật nâng cao


## Course Information - CSD301

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 1h final exam + 104h self-study
- **Pre-Requisite**: CSD202
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - CSD301
This course cover the following topics: 1. Divide-and-Conquer & Recursive strategies in algorithm 2. Probabilistic Analysis and Randomized Algorithms 3. Medians and Order Statistics 4. Advanced data structures like Red-Black Trees, B-Trees, Fibonacci Heaps and Strategies to Augmenting Data Structures 5. Dynamic Programming 6. Greedy Algorithms 7. Amortized Analysis 8. Data Structures for Disjoint Sets 9. Multithreaded Algorithms 10. Linear Programming 11. Computational Geometry 12. Approximation Algorithms

### Student Tasks - CSD301
- Students must attend more than 80% of contact sessions in order to be accepted to the final examination. - Student is responsible to do all assigned exercises given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to https://flm.fpt.edu.vn/ for up-to-date course information

## Course Learning Outcomes (CLOs) - CSD301

- **CLO1**: Apply divide-and-conquer & recursive strategies in designing algorithms
- **CLO2**: Estimate the computational complexity of an algorithm or a computational problem based on probabilistic distribution of the set of all possible inputs
- **CLO3**: Use advanced data structures like red-black trees, b-trees, fibonacci heaps and strategies to augmenting data structures
- **CLO4**: Apply advanced algorithm design techniques and implement advanced algorithms
