# LAB211 - OOP with Java Lab_Thực hành OOP với Java


## Course Information - LAB211

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 105h self-study
- **Pre-Requisite**: PRO192

### Description - LAB211
This course focuses on basic problems related to Java programming skills. Students are required to implement all assignments by him/her self in lab rooms. Each assignment must be completed continuosly in the defined time.

### Student Tasks - LAB211
- Students must attend at least 80% of contact slots in order to be accepted to the final results. - Students are responsible to conform to Lab Room Regulations - Use desktop computers only in lab room for learning purposes - Promptly access to the FU LMS at https://flm.fpt.edu.vn/ for up-to-date course information

### Tools - LAB211
NetBean 8.0.2 CheckStyle plugin for netbeans JAVA DOC JDK8 Tomcat Apache 8 Microsoft Excel 2007 or above Microsoft Word 2007 or above Microsoft Powerpoint 2007 or above Microsoft Windows XP or above

## Course Learning Outcomes (CLOs) - LAB211

- **CLO1**: Proficency in basic Java skills required in PRO192 Course
- **CLO2**: Be able to Independently complete small-size assignments
- **CLO3**: Be able to debug code using common tools
