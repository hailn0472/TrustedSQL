### Description - BDP302b
After learning the basic concepts in the first course, this Smart Contract course knowledge and skills about smart contacts, including roles, architecture and basic mechanism of smart contract concept in blockchain; the fundamental of Solidity programing languageto build smart contract in Ethereum Virtual Machine; how to build and apply smart contracts in blockchain, best practices in evaluating alternative smart contract solutions in blockchain

### Student Tasks - BDP302b
- Students should self-study all lessons on LMS in time - Pass all conditions before taking final exam in campus

## Course Learning Outcomes (CLOs) - BDP302b

- **CLO1**: Understand the roles, applications of smart contract in blockchain
- **CLO2**: Understand the method for developing smart contracts
- **CLO3**: Understand the Time elements in building smart contracts
- **CLO4**: Understand 'reverting' a transaction based on problem-specific validation and using a revert declaration,
- **CLO5**: Understand how to use Events to communicate with client
- **CLO6**: Know the best practices in evaluating smart contract
- **CLO7**: Know the best practices in designing smart contract
- **CLO8**: Know the best practices in using Remix IDE
- **CLO9**: Practice basic programing with Solidity
- **CLO10**: Design, build and deploy smart contracts in Ethereum
- **CLO11**: Understand definition of smart contract
- **CLO12**: Understand the address of a smart contracts and list of compilation artifacts of smart contracts
- **CLO13**: Understand the process to deploy smart contracts
- **CLO14**: Know the basics structure of Solidity
- **CLO15**: Understand the basic data type and operator of Solidity
- **CLO16**: Understand the important data structures in Solidity: address, mapping and message
- **CLO17**: Understand syntax and usage of arrays, enum, struct in Solidity
- **CLO18**: Understand the usage of function modifiers, the "require" clause and "assert" declaration in Solidity
