### Description - IOP490
The captone project provides students, working in groups, with a significant project experience in which they can integrate much of the material they have learned in their program, including matters relating to requirements, design, implementation, human factors, professionalism, and project management. Students should be expected to deliver one or several iterations of a software system, along with all artifacts appropriate to the process model they are using. These would likely include a) Project management Plan (perhaps updated regularly), b) System Requirements Specifications c) Architectural and Design Documents (Schematic, pcb, protocol, ...) d) Test Documentation e) System package & the user guides (package content, installation guide & user manuals)  All the documents in the project implementation process and the progress reports are required to write in English.

### Student Tasks - IOP490
- Choose appropriate project and form group (2-3 students/group). - Divide and schedule work among members. - Attend all scheduled meeting with supervisor. - Produce document and product according to project requirement and member work share. - Defend work infront of examination board, showing both project results and individual responsibility. In case of cheating found, the whole team is not allow to defend.

### Tools - IOP490
Appropriate tools for design and implementation.

## Course Learning Outcomes (CLOs) - IOP490

- **CLO1**: Use the knowledge of contemporary issues to identify a problem requiring technology intervention and specify the requiments for the proposed solution.
- **CLO2**: Design a iot solution, with consideration of techical & others factors.
- **CLO3**: Implement the design, including testing verification.
- **CLO4**: Apply project management principles to iot product development project.
- **CLO5**: Write a professional research report.
- **CLO6**: Practice oral presentation and inter-personal communications.
- **CLO7**: Exhibit professional working attitudes
