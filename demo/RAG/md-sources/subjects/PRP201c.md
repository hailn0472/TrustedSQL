## Course Information - PRP201c

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 60h online + 3h offline + 1h TE + 2h PE + 84h self-study
- **Pre-Requisite**: Recommend to have knowledge of basic programming in advance
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - PRP201c
This course will introduce fundamental programming concepts including data structures, networked application program interfaces, and databases, using the Python programming language. In the Capstone Project, students’ll use the technologies learned throughout the course to design and create your own applications for data retrieval, processing, and visualization.

### Student Tasks - PRP201c
- Student must get the certification of Python for Everybody specialization from Coursera to be accepted to the final examination

### Tools - PRP201c

## Course Learning Outcomes (CLOs) - PRP201c

- **CLO1**: Explain the basics of programming computers using Python
- **CLO2**: Understand fundamental programming concepts such as data structures
- **CLO3**: Create your own applications for data retrieval and processing
- **CLO4**: Describe the basics of the Structured Query Language (SQL) and database design
