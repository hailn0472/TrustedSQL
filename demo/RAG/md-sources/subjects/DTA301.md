# DTA301 - Data Analysis_Phân tích dữ liệu


## Course Information - DTA301

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 1h final exam + 104h self-study
- **Pre-Requisite**: PRO192, CSD201, DBI202, MAS291
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - DTA301
- Knowledge about data analysis concept, primary methods and processes, and analysis skills has become an essential part of an education in information system because main objectives of information systems are to support for enterprize's business. The data analysis is an very important aspect for making operation effectiveness of enterprize

### Student Tasks - DTA301
- Students must attend at least 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises and project given by instructor in class or at home and submit on time - Constantly follow announcements on intranet/LMS at https://cmshn.fpt.edu.vn for up-to-date course information regarding assignment submission and feedback on assignments and project work.

### Tools - DTA301
1. Rstudio 2. R programming language 3. Microsoft SQL Server 4. Hadoop Software package

## Course Learning Outcomes (CLOs) - DTA301

- **CLO1**: Understand the data analysis concepts and primary methods (Time Series Analysis, Classification, Regression, Clustering, Association Rules….)
- **CLO2**: Understand basic process in data analytics
- **CLO3**: Understand how to clean, and organize data for analysis, evaluate, and complete analysis and calculations using spreadsheets, SQL, R programming or Python
- **CLO4**: Design database schemas based on the conceptual model by using appropriate tools (spreadsheets, SQL, R programming, Tableau or Python)
- **CLO5**: Visualize and present data findings in dashboards, presentations and commonly used visualization platforms
