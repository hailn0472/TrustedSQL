# PRN292c - C# và .NET


## Course Information - PRN292c

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Online: 45 hours + 3 offline
- **Pre-Requisite**: PRO192 & DBI201
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - PRN292c
This course covers technical skills to design and develop high-quality object-oriented software systems using the C# programming language and students will learn how to develop video games using the C# programming language and the Unity game engine on Windows or Mac

### Student Tasks - PRN292c
Students complete the online courses MOOC1-MOOC3 (see details in the Materials page) and get certifications for MOOC1-MOOC3 to be allowed to take Final Exam

### Tools - PRN292c
- Internet - Visual Studio 2022 and MS SQL Server 2016 or later

## Course Learning Outcomes (CLOs) - PRN292c

- **CLO1**: Understand and using OOP in C# .NET
- **CLO2**: Understand and using LINQ & Generic collection in C# .NET
- **CLO3**: Be able to apply OOP and LINQ to devlop a project by C#.NET
- **CLO4**: Understand game programming with Unity
