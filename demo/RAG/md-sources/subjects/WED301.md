### Description - WED301
This course aims to provide technical knowledge and skills for student. Student will learn about web technologies such as HTML, CSS and Bootstrap. They have to practice to create website from the simple to a complex client-size or front-end web application. This is the advanced course of Web Design course, so student will continue their work in the end of the first course, and make an empirical version of last graphical design product in its project by applying web technologies. Beside the technologies, in this course student will learn about web design principles and approaches such as responsive web, and also understand techniques and tools to implement a website in a development processes. After this course, student can completely create a web themes includes images, icons, css(s), html(s) and javascript(s). Teaching method that used : Lectures, Tutorials, Discussions, Laboratory work, Group work, Seminar to help students approach the subject, understand the subject, apply it to design practice and achieve the learning outcomes of the subject.
