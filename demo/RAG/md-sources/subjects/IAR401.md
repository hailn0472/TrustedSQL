### Description - IAR401
This course will introduce the student to the essential aspects of information security and incident response (IR). The student will be provided with the tools, techniques and industry accepted methodologies so that upon completion of the course the student will be able to describe key concepts of network security and incident response and how those concepts apply to themselves and their organization.

### Student Tasks - IAR401

### Tools - IAR401
Internet, VMWare, Kali Linux, FTK, SleuthKit, EnCase, Wireshark, Netwitness Investigator

## Course Learning Outcomes (CLOs) - IAR401

- **CLO1**: Understand the IR process.
- **CLO2**: Write detailed incident response reports.
- **CLO3**: Create and implement comprehensive remediation plans
- **CLO4**: Build and equip an IR team for success; enhance an infrastructure or organization to facilitate the IR process.
- **CLO5**: Collect initial facts, understand methodical investigation and network evidence.
- **CLO6**: Develop leads, identify indicators of compromise, and determine incident scope.
- **CLO7**: Collect and preserve live data.
- **CLO8**: Perform forensic duplication.
- **CLO9**: Analyze data from networks, enterprise services, and applications.
- **CLO10**: Investigate Windows and Mac OS X systems.
- **CLO11**: Perform malware triage.
