### Description - DAP391m
This course will take students from the basics of data analysis with Python to build and evaluate data models. The students will learn to work with some Data Visualization tools and techniques and create interactive dashboards that allow even those without any Data Science experience to understand data better, and make more effective and informed decisions. A student will be able to write an application that leverages multiple Watson AI services. This course allows students to practice data scientists' work in real life when working with datasets.

### Student Tasks - DAP391m

### Tools - DAP391m
Jupyter Notebooks, JupyterLab, RStudio IDE, Git, GitHub, and Watson Studio.

## Course Learning Outcomes (CLOs) - DAP391m

- **CLO1**: Understand the basics of data analysis with Python to build and evaluate data models.
- **CLO2**: Understand how to import data from multiple sources, clean and wrangle data, perform exploratory data analysis (EDA), and create meaningful data visualizations.
- **CLO3**: Know difference ways to effectively visualize both small and large-scale data
- **CLO4**: Implement various types of basic and advanced graphs and charts like: Waffle Charts, Area Plots, Histograms, Bar Charts, Pie Charts, Scatter Plots, Word Clouds, Choropleth Maps, and many more
- **CLO5**: Implement an application that leverages multiple Watson AI services (Discovery, Speech to Text, Assistant, and Text to Speech)
- **CLO6**: Implementing different techniques to develop applications and AI powered solutions.
- **CLO7**: Implement the small mini capstone data science project includes steps: involving data collection, data wrangling, exploratory data analysis, data visualization, model development, model evaluation, and reporting
