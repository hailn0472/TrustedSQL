# PRJ321 - Java Web Application Development


## Course Information - PRJ321

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: 1 course = 30 sessions
1 session= 90 minutes
- **Pre-Requisite**: PRJ311
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - PRJ321
The course is Designed to enhance the practical ability of Students. In each session, There are 2 parts of the lecture will be delivered. The theoretical part, given in the form of short-slide, which only focus on the introduction and the key-ideas. The paractical part are given in form of the classworks (exercise in class) will help students understand the introduced topic by a practical approach. During the course, students will learn based on an assignment (given in the form of individual project). Student will decide the topic of the assignment under the supervision of the lecturer. The classworks provide the basic knowledge for the students. Students must investigate them-self and discuss with lecturer to complete the assignment. Beside the assignment (here we consider as long-homework) , there are few given workshops (short-homework). The workshops aim to help the lecturer to evaluate the learning progress of students. Based on that stackholders can recognize the shortcomings of skills and knowledge of the students.

### Student Tasks - PRJ321
- Attend more than 80% of contact hours in order to be accepted to the final examination - Actively participate in class activities - Fulfill tasks given by instructor after class - Use their own laptop in class only for learning purpose - Read the textbook in advance - Access the course website (www.cms.fpt.edu.vn) for up-to-date information and material of the course, for online supports from teachers and other students and for practicing and assessment.

### Tools - PRJ321
Web server application : Glassfish 4.0 or Tomcat 7 or higher IDE: Netbeans 8.1 or higher Java EE: 1.6 or higher MS SQL Server 2008 R2 or higher

## Course Learning Outcomes (CLOs) - PRJ321

- **CLO1**: review the static web page design
- **CLO2**: understand basic java web application
- **CLO3**: perform installing development environment components: JDK, IDE, Web server
- **CLO4**: applies Filter to build dynamic web application with MVC2 design pattern using Filter as Controller
- **CLO5**: Understands to struts framework?
- **CLO6**: Knows to create a simple web application uses Struts2
- **CLO7**: Knows some Struts components such as : Struts Action, Struts Validation Framework and Struts HTML tags
- **CLO8**: understand the concept of Servlet and how to use it
- **CLO9**: perform defining and writting the servlets.
- **CLO10**: understand the basic servlet structure and request / response headers.
- **CLO11**: apply the servlet to handle form data.
- **CLO12**: understand the File and Directory Structure, Deployment Descriptor Elements and war file
- **CLO13**: understand MVC 1 and MVC 2 design pattern, and using Servlet in MVC2 design Pattern using Servlet as Controller
- **CLO14**: understand how and why to use JSP.
- **CLO15**: discover the JSP Page.
- **CLO16**: understand how JSP works and JSP life cycle
- **CLO17**: gives an example of JSP Elements.
- **CLO18**: understand JSP Predefined Variable – Implicit Objects.
- **CLO19**: review the concept of JDBC
- **CLO20**: Implement CRUD java web application using MS SQL Server
- **CLO21**: understand the servlet container
- **CLO22**: understand the servlet context and innitialization parameters.
- **CLO23**: understand the servlet config and innitialization parameters
- **CLO24**: understand to the session lifecycle
- **CLO25**: discuss about the methods to manage session: cookie exchange and url rewrite.
- **CLO26**: understand what and why use Expression Language.
- **CLO27**: knows the EL syntax
- **CLO28**: understand how to use scoped variables and implicit variables in EL expressions
- **CLO29**: Comprehends the conditional evaluation.
- **CLO30**: understand the custom tags
- **CLO31**: Comprehends the Tag Extension Mechanism
- **CLO32**: Comprehends the Custom Tag Development Process
- **CLO33**: Understand to The “Classic” Custom Tag Event Model.
- **CLO34**: Knows the Tags and Implicit Variables.
- **CLO35**: Understands what and why use JSTL
- **CLO36**: Knows about the Tag libraries included in jstl.
- **CLO37**: practice with detailed glance to the jstl-core library
- **CLO38**: understands the purpose of Filter
- **CLO39**: create, declaring and mapping Filter
