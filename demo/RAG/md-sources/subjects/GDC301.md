### Description - GDC301
This comprehensive Basic Unity Training Program is designed to equip participants with essential skills in Unity game development, empowering them to create engaging and interactive 2D and 3D games. Building upon a strong foundation in C# programming, the course delves into advanced topics such as 3D game development, physics, animations, and user interface design. Through a combination of theoretical lectures, hands-on labs, and collaborative projects, participants will gain practical experience and confidence in using Unity to bring their game ideas to life.  Key Learning Outcomes: - Master C# Programming: Gain a deep understanding of C# syntax, data structures, algorithms, and object-oriented programming principles. - Navigate the Unity Environment: Become proficient in using Unity's interface and tools for game development. - Develop 3D Games: Learn the fundamentals of 3D game development, including rendering, lighting, animations, and physics. - Create Engaging Game Worlds: Master the art of designing game objects, animations, and physics components to create immersive and interactive game environments. - Build User-Friendly Interfaces: Design intuitive and visually appealing user interfaces that enhance the player experience. - Develop Games from Start to Finish: Complete hands-on projects, applying your knowledge to create your own small games and interactive applications. - Collaborate Effectively: Work collaboratively with teammates to develop game projects, fostering effective communication and teamwork skills.

## Course Learning Outcomes (CLOs) - GDC301

- **CLO1**: Understand C# Programming Fundamentals: Syntax and Data Types, Control Flow, Functions and Methods, Classes and Objects, Debugging
- **CLO2**: Understand C# data structures (lists, stacks, queues, trees) and algorithms (sorting, searching); Event Handling
- **CLO3**: Understand the Unity interface and basic tools for game development
- **CLO4**: Understand 3D Game Development; Rendering and Lighting; Animations and Physics
- **CLO5**: Create and manipulate game objects, animations, and physics components
- **CLO6**: Design user interfaces and handle user input effectively
- **CLO7**: Develop small games and interactive applications using Unity
- **CLO8**: Collaborate effectively in a team environment for game development projects.
