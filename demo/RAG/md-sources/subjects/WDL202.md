- **Credits**: 3

### Description - WDL202
Students will continue developing design skills for web, with a focus on typography, UI design, and use digital design tools to create graphic elements and content. Emphasis will be on critical thinking, executing design strategies and concepts, and comprehensive creative solutions to design problems in the web and mobile space.

### Student Tasks - WDL202
- Attend at least 80% of contact hours in order to be accepted to the final examination - Actively participate in class activities - Fulfil tasks given by intructor after class - Use their own laptop in class only for learning purpose - Read the textbook in advance - Access the course website (https://flm.fpt.edu.vn/) for up-to-date information and material of the course. - Computer with some version of photograph editing software such as Photoshop, Microsoft Word for written assignments, and POWERPOINT for presentations - Have color papers, Color Pencils, scissors... - Complete course's Portfolio with full contents of exercises and submit to the teacher 1 day after the course.

## Course Learning Outcomes (CLOs) - WDL202

- **CLO1**: - Define user experience design and understand what draws people to the field - Ask the questions that are important to have answer before the project begins (or at least before you start to work on it)
- **CLO2**: Start things off right with efficient meetings, clear objectives, and well-understood approval points
- **CLO3**: Define project requirements that are unambiguous and easy to prioritize, drawn from business stakeholders and users
- **CLO4**: Learn about your users and represent their needs throughout the project
- **CLO5**: Choose and utilize the tools and techniques that enable you to bring visual ideas to your project team quickly
- **CLO6**: Ensure your site is easily found and searched by users and by search engines Critically analyse and reflect upon project feedback.
- **CLO7**: Be able to use design tools to create clean and well-structured UI for common design patterns
