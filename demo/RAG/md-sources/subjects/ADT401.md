### Description - ADT401
This course aims to provide student understanding on techniques, tools and skills to do a practical application design project. To study this course, student must have basic knowledge related to Interaction and UX Design, understanding principles and agile process applied in a mobile design project. In this course, student will perform a design project individually and have to work with programmer to transform an idea to a product. They will learn how to do from a research to design and implement an application project. They will learn about how to run a study of domain interested, how to make use-case list and draw flow diagram. They will be taught about the way to write a proposal for a project. In design phase, there are alot of things student must aware about, so they will be taught about them including rules, principles and good practices such as Realism, Fitts's Law, Animation, Speed and etc.. Testing techniques such as A/B Testing, Usability Testing will also be explained in this course. Student will be evaluated according to how his/her applied knowledge gained from this course to the course's project.

## Course Learning Outcomes (CLOs) - ADT401

- **CLO1**: Discuss about any aspects related to design a mobile application and process
- **CLO2**: Perform a research in interesting field and write a proposal for the application project.
- **CLO3**: Generate sketching and paper prototypes
- **CLO4**: Create an digital prototype on InVisionApp or similar tools
- **CLO5**: Improve a design product by applying principles and other good practices
- **CLO6**: Understand about Important of evaluation works in implementation phase, especially testing techniques such as Usability Testing, A/B Testing, Remote Testing....
- **CLO7**: Perform Usability Testing in a mobile application design project
- **CLO8**: Manage any work activities in a mobile application design including cooperate with programmers
- **CLO9**: Have a proficient in presentation and teamworks.
