# MSS301 - Microservices with Spring Cloud_Microservices với Spring Cloud


## Course Information - MSS301

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 1h final exam + 85' practical exam +102.6h self-study
- **Pre-Requisite**: SBA301
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - MSS301
Upon completion of this course students shoud: 1. Understand the followings: • Microservices, Microservices architecture. • The basics of Spring Cloud and its architecture • The configuration and implementation using Spring Cloud • The microservices architecture using Spring Cloud. • The deployment of microservices-based applications using Docker and Spring Cloud tools  2. Be able to: • Explain about Microservices architecture and its benefits, including scalability, resilience, and fault tolerance. • Explain about Spring Cloud and its architecture • Configure and implement Spring Cloud in a project • Design and implement a microservices architecture using Spring Cloud • Design, build, and deploy microservices-based applications using Docker and Spring Cloud tools  3. Be able to work in team and present group's results

### Student Tasks - MSS301
- Students must attend at least 80% of contact sessions in order to be accepted to the final examination. - Student is responsible to do all assigned exercises given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to the FU CMS at http://flm.fpt.edu.vn for up-to-date course information

### Tools - MSS301
- Internet - IntelliJ IDEA or Sping Tool 4 for Eclipse/Visual Studio Code - JDK 20 - Platform: SpringBoot 3

## Course Learning Outcomes (CLOs) - MSS301

- **CLO1**: Understand of Microservices architecture and its benefits, including scalability, resilience, and fault tolerance.
- **CLO2**: Understand the basics of Spring Cloud and its architecture
- **CLO3**: Design and implement a microservices architecture using Spring Cloud.
- **CLO4**: Design, build, and deploy microservices-based applications using Docker and Spring Cloud tools, including configuration and management of services
