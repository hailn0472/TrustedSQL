# HSF302 - Working with Spring Framework_Làm việc với Spring Framework


## Course Information - HSF302

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 93.75h contact hours + 1h final exam + 85' practical exam + 102,6h self-study
- **Pre-Requisite**: PRJ301
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - HSF302
Upon completion of this course students shoud: 1. Understand the followings: • Basic concepts of Java FX to build Desktop Application • Basics of Object-Relational Mapping (ORM) with JPA and how it simplifies database interactions. • Spring Framework, Spring Boot, which provides a comprehensive ecosystem for building enterprise-level applications. • Spring Framework's dependency injection, and web frameworks to build robust and scalable applications  2. Be able to: • Use JPA ORM tool to map Java objects to database tables. • Use Spring Framework's dependency injection, and web frameworks to build robust and scalable applications. • Develop Cross-platform Desktop applications and support for user experience (UI & UX)  3. Be able to work in team and present group's results

### Student Tasks - HSF302
- Students must attend at least 80% of contact sessions in order to be accepted to the final examination. - Student is responsible to do all assigned exercises given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to the FU CMS at http://flm.fpt.edu.vn for up-to-date course information

### Tools - HSF302
- Internet - IntelliJ IDEA - Platform : Java Development Kit 21 - Scene Builder 23

## Course Learning Outcomes (CLOs) - HSF302

- **CLO1**: Describe the basics of Object-Relational Mapping (ORM) and how it simplifies database interactions.
- **CLO2**: Describe the concepts of Spring Framework and Spring Boot
- **CLO3**: Describe how Spring Data working with various data sources
- **CLO4**: Undersatnd Spring MVC provides a comprehensive programming and configuration model for modern Java-based enterprise applications.
- **CLO5**: Create Cross-Platform applications using JavaFX. JavaFX is platform-independent, which means that JavaFX applications (CRUD) can run on different operating systems such as Windows, macOS, and Linux
- **CLO6**: Develop teamwork skills, communication skills (including presentation skills)
