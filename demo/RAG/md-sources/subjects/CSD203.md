### Description - CSD203
This course introduces the basic concepts of data structures and algorithms in data structures with the use of Python. Topics introduced in the course include the basics of algorithm analysis, basic data structures (including stack, queue, linked list, hashtable, tree), recursion and some important applications of these data structures and algorithms.

## Course Learning Outcomes (CLOs) - CSD203

- **CLO1**: LO1. Describe the list data structure and its’ different way of implementations. Implement the singly linked list.
- **CLO2**: LO2. Define stack and queue. Describe basic operations and the use of these structures.
- **CLO3**: LO3. Describe about recursive definitions, algorithms, functions and their implementation and use.
- **CLO4**: LO4. Explain about general tree, Binary Tree and Binary Search Tree (BST). Implement BST with basic operations.
- **CLO5**: LO5. Díscuss about graphs and their application. Implement a graph with some basic operations.
- **CLO6**: LO6 Explain the operation and performance of some basic and advanced sorting alggorithms
- **CLO7**: LO7 Explain about hashing and application.
- **CLO8**: LO8 Describe the Text Processing problem and its’ application. Explain the Huffman, LZW and Run-length encoding Algorithms.
