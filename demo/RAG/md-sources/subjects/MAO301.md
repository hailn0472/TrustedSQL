# MAO301 - Combinatorial Optimization


## Course Information - MAO301

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Contact time: 30 sessions
Lectures: 15 ; Tutorials: 15
1 session = 90'
- **Pre-Requisite**: MAD121 and MAA101
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - MAO301
This course provides an introduction to combinatorial optimization. It discusses linear programming techniques and various fundamental graph-theoretic algorithms. This course covers, among others, shortest path algorithms, minimum spanning trees, matching, coverings and network flows.

### Student Tasks - MAO301
Students must attend more than 80% of contact hours in order to be accepted to the final examination.
