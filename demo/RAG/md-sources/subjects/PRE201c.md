### Description - PRE201c
In this course, students will learn the essentials of Microsoft Excel. Students will be able to expertly navigate the Excel user interface, perform basic calculations with formulas and functions, professionally format spreadsheets, and create visualizations of data through charts and graphs. Students will also build a solid layer of more advanced skills so they can manage large datasets and create meaningful reports. These key techniques and tools will allow students to add a sophisticated layer of automation and efficiency to everyday tasks in Excel.
