### Description - AMR402
This course covers the fundamentals of working in CG (Computer Graphics) with Maya. It provides an overview of maya, basic modeling tools, working with UVs, textures,basic lighting and rendering using the provided software.

### Student Tasks - AMR402
- Attend at least 80% of contact hours in order to be accepted to the final examination - Actively participate in class activities - Fulfill tasks given by instructor after class - Use their own laptop in class only for learning purpose - Read the textbook in advance > - Access the course website (https://flm.fpt.edu.vn/) for up-to-date information and material of the course, for online supports from teachers and other students and for practicing and assessment.

## Course Learning Outcomes (CLOs) - AMR402

- **CLO1**: Apply different modeling techniques in Maya: Poly modeling, Subdivision modeling and NURBS modeling
- **CLO2**: Understand topology and apply it appropriately.
- **CLO3**: Create a 3D character model that’s proper for aimation
- **CLO4**: Create and modify material in Maya
- **CLO5**: Setup lighting, camera and render a scene using Arnold Renderer
- **CLO6**: Having a positive attitude and a professional working style
