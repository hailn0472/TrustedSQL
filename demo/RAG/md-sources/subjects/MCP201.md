- **Credits**: 3

- **Min Avg Mark To Pass**: 5

### Description - MCP201
- Learn how to implement real-world embedded system projects on a simulated microcontroller using the Mbed API. - Modify skeleton code to implement functionality for multiple applications: an audio wave generator, an audio player, and controlling peripherals using analog and digital I/O interfaces, interrupts, timers, and pulse width modulation. - Learn key features of Arm processors and architectures and how a modern API Learn key serial communication protocols used in the embedded environment including SPI, UARTs and I2C; evaluating their benefits and limitations. Learn the features of a Real-time Operating System (RTOS) and how it facilitates multitasking in an microcontroller. - Develop working embedded prototypes using the Arm Mbed API, microcontroller on the ST Nucleo F401RE board and low cost parts. Learn hardware and software theory, immediately applied in practice. Apply your knowledge to create a user interface, temperature sensing system, and music player - with ideas to develop each further. - Apply threads, mutex, semaphores and interrupts to write a fully-functioning multitasking program. Learn deeper programming skills with C/C++, applying these to use of the powerful Mbed API. Learn staged circuit development and troubleshooting skills.

## Course Learning Outcomes (CLOs) - MCP201

- **CLO1**: Understand and describe about a program, and the way it works on computer.
- **CLO2**: Demonstrate about variables, expressions and basic operations and illustrate them by program examples.
- **CLO3**: Explain the meaning and use of Logic constructs in C Language. Describe about programming styles.
- **CLO4**: Describe about Modularity and Functions in C programs and their use.
- **CLO5**: Understanding and using pointers in programs.
- **CLO6**: Discuss about C Libraries and their use.
- **CLO7**: Discuss about Arrays, Struct and their use in C programs.
- **CLO8**: Discuss about Strings and their use in C programs.
- **CLO9**: Discuss about Files and their use in C programs.
