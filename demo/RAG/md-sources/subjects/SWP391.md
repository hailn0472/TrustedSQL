## Course Information - SWP391

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 45h contact hours + 105h self-study
- **Pre-Requisite**: PRJ301, SWE201c
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - SWP391
This course focuses on designing, developing, and integrating the basic Web-based system/application using Java Web or .NET technologies (with the system requirements, technical framework & DBMS as assigned/agreed by the teacher) Students are required to build the system in teams, 4-5 members/team as appointed by the teacher. After the course, students will be able to achieve web programing proficiency with the following skills by practicing with other members in the assigned team - Proficiency in common web techniques and basic Java or .NET Web development skills - Proficiency in front end skills (HTML, CSS, JS) required for the industry - Analyze & design the solution following the object oriented models - Co-ordinate with the others to complete the project works

### Student Tasks - SWP391
'- Build the team & select/receive the software topic to develop with arrangement/guide from the teacher - Select the team leader and setup/configure project development and management environments (source codes, tasks, issues, milestones) on the GitLab (or GitHub) & project documents management on the OneDrive (or Google Drive) - Get the detailed assignment from the teacher, plan the project tasks, and execute the project accordingly - Students must attend at least 80% of contact slots in order to be accepted to the final presentation. - Student is responsible to do all exercises given by the teacher in class or at home and submit on time - Constantly follow the teacher's guides/references for up-to-date course information regarding assignment submission and feedback on assignments and project work. - Using the GitLab (or GitHub) to collaborate in every phase of the project by all the team members

### Tools - SWP391
One Drive or Google Drive for document management GitLab (https://gitlab.com/) for issue and code version management DBMS: as assigned/agreed with the teacher Java tools • Tomcat server • Java JDK version 1.6 or higher, NetBeans 13 .NET tools • Microsoft Internet Information Services server • Microsoft Visual Studio version 2019 or higher

## Course Learning Outcomes (CLOs) - SWP391

- **CLO1**: Can study & analyze to understand the project requirements, actively make questions if necessary
- **CLO2**: Understand and applying MVC design pattern, knowledges of OOP in designing code modules as well as designing database based on designed UI
- **CLO3**: Proficiency in Web programming skills, based on the Java or .NET technologies
- **CLO4**: Exhibit professional working attitudes
- **CLO5**: Practice oral presentation and inter-personal communications.
