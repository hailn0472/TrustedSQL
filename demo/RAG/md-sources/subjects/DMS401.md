### Description - DMS401
Data mining is intended to analyze the huge volumes of data and information generated by businesses, science, web, and other sources and how to separate true patterns there from random and false ones. The rise of big data has the potential to inform decisions, and visual representations can play a crucial intermediate role in our daily information consumption. Data mining is needed to make sense and use of the rapidly growing data and is an essential field of the 21st century. Data mining has important applications in many scientific fields such as medicine, business, e-commerce, sport, … In particular data-mining- based solutions are essential for many Information Assurance problems. The course provides an introduction to data mining with practical machine learning tools and techniques which can be applied for a further development in Information Assurance.

## Course Learning Outcomes (CLOs) - DMS401

- **CLO1**: Understanding a wide range of data mining applications, particularly to many Information Assurance problems.
- **CLO2**: Approaching data mining as a process with competency in the use of CRISP-DM, particularly the phases of business and data understanding, exploratory data analysis, modeling, evaluation, and deployment.
- **CLO3**: Being proficient with leading data mining tools, e.g. WEKA, Clementine by SPSS, the Python and R languages.
- **CLO4**: Preparing data for data mining, e.g. putting data into a standard format.
- **CLO5**: Identifying machine learning algorithms that have the potential to address a given data mining task.
- **CLO6**: Applying a wide range of clustering, estimation, prediction, and classification algorithms.
- **CLO7**: Understanding the mathematical and statistical foundations of the algorithms.
- **CLO8**: Analyzing the results of data mining experiments and coming to conclusions.
- **CLO9**: Being able with team-work to write a program recreating an existing data mining method, a paper analyzing available data mining software (in terms of capabilities, flexibility, robustness, cost, learning curve), and to carry out a complete data mining project.
