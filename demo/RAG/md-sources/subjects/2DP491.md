# 2DP491 - Digital project 2D_Dự án kỹ thuật số 2D


## Course Information - 2DP491

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h)
= 45h contact hours + 105h self-study
- **Pre-Requisite**: (ANB401 or ANB402), ANT401, ANO301
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - 2DP491
Description: · This course will focus on facilitating the student’s production of 2D animated project. · Idea development, test, problem solving, plan development and time manage will be applied with the selection of appropriate techniques, content and types of 2D animation. · Students work directly with lecturer, with proper explanation and instruction to develop every stage of the project.  Objective: · To get used to the implementation of Capstone project. · To have thorough understanding of the whole process to develop short animation from idea to screen showing stage. · To develop skills to produce a completed 2D animation. · To develop a short animation project with proper time management to complete by deadline.

### Student Tasks - 2DP491
- Attend at least 80% of contact hours in order to be accepted for the final examination - Actively participate in class activities - Fulfill tasks given by instructor after class - Use their own laptop in class only for learning purpose - Read the textbook in advance

## Course Learning Outcomes (CLOs) - 2DP491

- **CLO1**: Compile, complete and improve 2D animation knowledge that has been introduced.
- **CLO2**: Understand process to implemen a 2D animation project, task and time demarcation, get used to Capstone Project
- **CLO3**: Create a 2D animated project developed from visual design and personal graphic research
- **CLO4**: Complete a project in a profesional and timely manner
- **CLO5**: Students have good presentation skills, work in groups and know how to evaluate products.
- **CLO6**: Having a professional working style.
- **CLO7**: Understand and able to apply cinematic language into the project
