# PRO201 - FRONT-END WEB DEVELOPMENT


## Course Information - PRO201

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Contact hours: 1 session=90'
Lectures: 15 sessions
Tutorials: 15 sessions
- **Pre-Requisite**: PRF192
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - PRO201
This course introduces: - The Hypertext Markup Language for creating webpages. - The Cascading Style Sheets for customizing the way data are presented in browsers. - The client-site Javascript for creating dynamic web pages.

### Student Tasks - PRO201
- Students must attend more than 80% of contact sessions - Student is responsible to do all exercises given by instructor in class or at home and submit on time - Promptly access to the FU CMS at cmshn.fpt.edu.vn for up-to-date course information

### Tools - PRO201
- Internet - Notepad, Dreamweaver for creating web pages. - Browsers: The newest Google Chrome/ FireFox version

## Course Learning Outcomes (CLOs) - PRO201

- **CLO1**: Understand the concepts of HTML, CSS, JavaScript
- **CLO2**: Understand Web page structure.
- **CLO3**: Understand Web site structure.
- **CLO4**: Understand The way a Web page is presented in browsers.
- **CLO5**: Create static web pages using HTML.
- **CLO6**: Customize data formats when they are presented in browsers.
- **CLO7**: Create dynamic client-side Web pages using Javascript.
- **CLO8**: Improve study skills (academic reading, information searching, ...)
