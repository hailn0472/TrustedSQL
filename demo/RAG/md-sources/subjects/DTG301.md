# DTG301 - Digital Tool - Interactive


## Course Information - DTG301

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Duration: 30 slots (1 slot = 90 minutes)
- **Pre-Requisite**: WMT201
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - DTG301
- The course is applied in class having fully requirements learning tools. - Students are able to learn how to create a website by Adobe Flash. - Students have the opportunity to use the knowledge of colors, shapes ... to create motion graphics through the practice in class from the basic theories. - Student's project will be reviewed and evaluated by lecturer and all the students after class.

### Tools - DTG301
1. FPT University: - Room with projector - Internet connection - Sticker notes - Whiteboard marker (include 3 color: blue, red and black)   2. Student's preparation: - Laptop with external mouse - Portfolio - A3, A4 paper size - Pencil, eraser, ruler - Tape
