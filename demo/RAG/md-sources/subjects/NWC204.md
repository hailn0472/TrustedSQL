### Description - NWC204
This course is designed based on the first course of CCNA. The first course in the CCNA curriculum introduces the architectures, models, protocols, and networking elements that connect users, devices, applications and data through the internet and across modern computer networks - including IP addressing and Ethernet fundamentals. By the end of the course, students can build simple local area networks (LANs) that integrate IP addressing schemes, foundational network security, and perform basic configurations for routers and switches. Listed below are the current set of modules and their associated competencies outlined for this course. Each module is an integrated unit of learning that consists of content, activities and assessments that target a specific set of competencies. The size of the module will depend on the depth of knowledge and skill needed to master the competency. Some modules are considered foundational, in that the artifacts presented, while not assessed, enable learning of concepts that are covered on the CCNA certification exam.

## Course Learning Outcomes (CLOs) - NWC204

- **CLO1**: Explain the advances in modern network technologies
- **CLO2**: Calculate an IPv4 subnetting scheme to efficiently segment a network.
- **CLO3**: Implement an IPv6 addressing scheme.
- **CLO4**: ICMP Use various tools to test network connectivity.
- **CLO5**: Compare the operations of transport layer protocols in supporting end-to-end communication.
- **CLO6**: Explain the operation of application layer protocols in providing support to end-user applications.
- **CLO7**: Configure switches and routers with device hardening features to enhance security.
- **CLO8**: Implement a network design for a small network to include a router, a switch, and end devices.
- **CLO9**: Implement initial settings including passwords, IP addressing, and default gateway parameters on a network switch and end devices.
- **CLO10**: Explain how network protocols enable devices to access local and remote network resources.
- **CLO11**: Explain how physical layer protocols, services, and network media support communications across data networks.
- **CLO12**: Explain how media access control in the data link layer supports communication across networks
- **CLO13**: Explain how Ethernet operates in a switched network
- **CLO14**: Explain how routers use network layer protocols and services to enable end-to-end connectivity.
- **CLO15**: Explain how ARP and ND enable communication on a network.
- **CLO16**: Implement initial settings on a router and end devices.
