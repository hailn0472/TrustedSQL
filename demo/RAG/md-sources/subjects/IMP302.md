### Description - IMP302
This course covers signal processing techniques specialized for handling 2D (images) and 3D (videos) signals. Students will learn fundamental tools and techniques for processing images and videos, and will learn to apply them to a range of practical applications. Specific focus will be on transform-domain, PDE and sparsity-based models and associated optimization techniques. These techniques will be enriched via applications in mobile devices, medical image processing, and compressive sensing.

## Course Learning Outcomes (CLOs) - IMP302

- **CLO1**: Comprehend the image processing fundamentals and enhancement techniques in spatial and frequency domain
- **CLO2**: Describe the color image fundamentals, models and various restoration techniques
- **CLO3**: Design and Analyze the image compression systems
- **CLO4**: Outline the various image segmentation and morphology operations
- **CLO5**: Comprehend the basics of video processing and video coding
