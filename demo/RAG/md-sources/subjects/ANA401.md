### Description - ANA401
This course covers character rigging and animation in Maya. Students will learn to rig characters, animate with keyframe techniques, analyze body language and expressions and apply animation principles for realistic motion. They will be able to create and render a short animation scene using Maya and compositing software while also developing a positive and professional working style.

## Course Learning Outcomes (CLOs) - ANA401

- **CLO1**: Rig a character using Maya
- **CLO2**: Animate objects and the characters using keyframe animation techniques in Maya
- **CLO3**: Analyze body language, body mechanics and facial expressions
- **CLO4**: Apply animation principles to create convincing motion
- **CLO5**: Develop skills in animating the characters depicting body mechanics and facial expressions
- **CLO6**: Create and render animation a short scene using Maya and compositing software
- **CLO7**: Demonstrate a positive attitude and a professional working style.
