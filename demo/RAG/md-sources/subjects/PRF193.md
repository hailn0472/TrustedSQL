### Description - PRF193
This course equips students with knowledge of the C/C++ programming language from basic to advanced, *) Basics - C/C++ Keywords, C/C++ Variable Types, Lvalues and Rvalues, Operators in C/C++, Strings, Arrrays, Pointerts, C/C++ References, C/C++ Basic Input/Output ... - OOP *) Advance: C/C++ Standard Template Libaries, Files/streaming ,Exception, template, multithread, smartpointer, etc.

## Course Learning Outcomes (CLOs) - PRF193

- **CLO1**: Understand and apply fundamental concepts in C/C++ programming, including C/C++ keywords, variable types, Lvalues and Rvalues, operators, strings, arrays, and pointers.
- **CLO2**: Implement decision-making constructs (if-else, switch), loops (for, while, do-while), and modify program flow using control flow keywords (break, continue, goto).
- **CLO3**: Define, declare, and implement functions in C/C++, using modular programming techniques such as recursion, function pointers, and parameter passing.
- **CLO4**: Understand and apply object-oriented programming (OOP) principles like encapsulation, inheritance, and polymorphism. Use pointers, references, dynamic memory allocation, and smart pointers in C++ for efficient memory management. Avoid memory leaks and dangling pointers while working with classes, constructors, destructors, templates, and exceptions.
- **CLO5**: Open, read, write, and close files using C/C++ file handling functions and streams. Distinguish between binary and text file formats and perform random access operations.
