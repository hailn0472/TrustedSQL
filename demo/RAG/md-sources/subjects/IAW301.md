### Description - IAW301
This course provides an immersive learning experience in the field of web application security, featuring the use of PortSwigger as our primary lab material. PortSwigger offers a powerful platform for hands-on exploration of web application vulnerabilities and security best practices. Through this course, students will gain a deep understanding of web application security principles and develop practical skills in a controlled, real-world environment.

### Student Tasks - IAW301
- Students will engage with PortSwigger, a professional-grade web security testing tool, to explore real-world web vulnerabilities, assess security risks, and practice ethical hacking techniques. - Students must attend at least 80% of contact sessions in order to be accepted to the final examination. - Students are responsible to do all exercises, assignments and labs given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to the https://flm.fpt.edu.vn/ for up-to-date course information

## Course Learning Outcomes (CLOs) - IAW301

- **CLO1**: Gain an introductory understanding of web security principles and their importance in the context of web applications.
- **CLO2**: Develop the skills to identify and exploit race conditions, especially related to limit overruns.
- **CLO3**: Understand the concept of path traversal vulnerabilities and how they can be exploited.
- **CLO4**: Gain the skills to identify and exploit vulnerabilities related to file uploads.
- **CLO5**: Understand the concept of information disclosure vulnerabilities and their potential impact on web application security.
- **CLO6**: Examine vulnerabilities in various authentication mechanisms (password-based and multi-factor authentication).
- **CLO7**: Learn how to identify, exploit IDOR and Privilege escalation.
- **CLO8**: Explore vulnerabilities related to OAuth 2.0 authentication mechanisms.
- **CLO9**: Understand SQL injection vulnerabilities and their exploitation.
- **CLO10**: Understand OS Command Injection vulnerabilities and their exploitation.
- **CLO11**: Learn to identify and exploit reflected XSS vulnerabilities.
- **CLO12**: Understand SSRF vulnerabilities and the potential risks they pose.
