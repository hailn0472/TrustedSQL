### Description - ECP491
The Captone Project is a combination of theory, practice, application, and attitudes accompany the construction of each course. Students can work in groups, with a significant project experience in which they can integrate much of the materials they have learned in their program. The project is recommeded to be as realistic as possible. Furthermore, the project may take various forms (e.g., written thesis, applied design project, simulation project or software program) based on the specific discipline. There are several paths that student can select to do the capstone projects: - Electronics and Embedded Systems - Wireles and Mobile Communications - Optical Communications - Networking

### Student Tasks - ECP491
# Choose project at project market and form group. # Divide and schedule work among members # Attend all scheduled meeting with supervisor. # Produce document and product according to project requirement and member work share. # Defence work infront of examination board, showing both project results and individual responsibility.
