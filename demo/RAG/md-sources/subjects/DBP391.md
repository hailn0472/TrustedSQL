### Description - DBP391
The objective of the course is to help students apply the knowledge about data mining to apply in practice to solve problems to ensure requirements such as: - Use the discussed data mining techniques in practice, - Identify relevant data mining techniques from research articles for a given problem, - Formulate a methodological description on how a problem ought to be solved using data mining, - Analyse results and models from a data mining project. - Identify problems for which data mining is appropriate to use, - Select appropriate evaluation methods based on the data mining task at hand. - Learn about the legal and ethical aspects of data collection and use. - Analyze data mining problems and reason about the most appropriate methods to apply to a given dataset and knowledge extraction need. - Implement basic pre-processing, association mining, classification and clustering algorithms. - Apply and reflect on advanced pre-processing, association mining, classification and clustering algorithms. - Work efficiently in groups and evaluate the algorithms on real-world problems.
