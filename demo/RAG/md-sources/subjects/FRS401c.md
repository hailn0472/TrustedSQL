### Description - FRS401c
This course will introduce the student to the essential aspects of information security and network forensics. The student will be provided with the tools, techniques and industry accepted methodologies so that upon completion of the course the student will be able to describe key concepts of network security and forensics and how those concepts apply to themselves and their organization. The course is based on Courses 1, 2 and 6 of the SSCP Professional Training Certificate, the whole will show employers you have the IT security foundation to defend against cyber attacks – and puts you on a clear path to earning SSCP certification.

## Course Learning Outcomes (CLOs) - FRS401c

- **CLO1**: Understand the different access control systems and how they should be implemented to protect the system and data using the different levels of confidentiality, integrity, and availability. LO1.1 Describe how to implement Authentication mechanisms LO1.2 Identify and operate internetwork trust architectures LO1.3 Describe the process of administering identity management life cycle LO1.4 Implement the different types of access controls (Subject/Object based)
- **CLO2**: Achieve basic security concepts and the application of those concepts in the day to day operation and administration of enterprise computer systems and the information that they host. LO2.1 Define Code of Ethics, describe the security concepts, Document and operate security controls" LO2.2 Describe the asset management process LO2.3 Implement and assess compliance controls LO2.4 Describe the change management process LO2.5 Contribute to the security awareness training program and physical security operations
- **CLO3**: Know concepts in endpoint device security, cloud infrastructure security, securing big data systems, securing virtual environments, and how an organization can protect itself from these attacks. LO3.1 Identify malicious activity, describe malicious code and the various countermeasures LO3.2 Describe the processes for operating endpoint device security, and mobile device management processes LO3.3 Describe the process for configuring cloud security LO3.4 Explain and summarize the process for securing big data systems and virtual environments
