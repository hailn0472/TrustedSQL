## Course Information - BDM201

### Description - BDM201
In business, good decision making requires the effective use of information. This unit gives learners the opportunity to examine a variety of sources and develop techniques in relation to four aspects of information: data gathering, data storage, and the tools available to create and present useful information. Specifically, learners will use spreadsheets and other software for data analysis and the preparation of information. The use of spreadsheets to manipulate of numbers, and understanding how to apply the results, are seen as more important than the mathematical derivation of formulae used. Learners wil lgain an appreciation of information systems currently used at all levels in an organisation as aids to decision making.

## Course Learning Outcomes (CLOs) - BDM201

- **CLO1**: create a plan for the collection of primary and secondary data for a given business problem
- **CLO2**: prepare a business presentation using suitable software and techniques to disseminate information effectively
- **CLO3**: produce a formal business report
- **CLO4**: use appropriate information processing tools
- **CLO5**: prepare a project plan for an activity and determine the critical path
- **CLO6**: use financial tools for decision making.
- **CLO7**: present the survey methodology and sampling frame used
- **CLO8**: design a questionnaire for a given business problem
- **CLO9**: create information for decision making by summarising data using representative values
- **CLO10**: analyse the results to draw valid conclusions in a business context
- **CLO11**: analyse data using measures of dispersion to inform a given business scenario
- **CLO12**: explain how quartiles, percentiles and the correlation coefficient are used to draw useful conclusions in a business context
- **CLO13**: produce graphs using spreadsheets and draw valid conclusions based on the information derived
- **CLO14**: create trend lines in spreadsheet graphs to assist in forecasting for specified business information
