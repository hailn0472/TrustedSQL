# IBSTPI001 - Kỹ năng sư phạm theo chuẩn IBSTPI

- **Credits**: 0
- **Degree Level**: Bachelor

- **Pre-Requisite**: None
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - IBSTPI001
The course provides the nesessary knowledge and skills for students to be able to participate in the training field after completion of their study program. It follows the key compentencies for effective classroom training defined by the International Board of Standards for Training, Performance and Instruction (IBSTPI) and recognized throughout the technical training industry. Mastery of these skills together with expertise in the course subject area will ensure a high quality of training. The social constructivist teaching/learning approach is used to deliver this course.

### Student Tasks - IBSTPI001
- Students work in groups in order to elaborate the contents of the course, then present, counter-argument during class hours under instructor's guidance and peer feedback by using Edunext. - Students must attend more than 80% of class hours in order to be accepted to the final examination.

### Tools - IBSTPI001
Internet, Laptop, Edunext, EOS

## Course Learning Outcomes (CLOs) - IBSTPI001

- **CLO1**: Aware of responsibilities of instructors
- **CLO2**: Be able to describe how to provide positive reinforcement and motivational incentives.
- **CLO3**: Be able to describe how to use instructional methods appropriately.
- **CLO4**: Be able to describe how to use media effectively.
- **CLO5**: Be able to describe how to evaluate learner performance.
- **CLO6**: Be able to describe how to evaluate delivery of instruction.
- **CLO7**: Be able to describe how to report evaluation information.
- **CLO8**: Be able to describe how to analyze course materials and learner information.
- **CLO9**: Be able to describe how to assure preparation of the instructional site.
- **CLO10**: Be able to describe how to establish and maintain instructor credibility.
- **CLO11**: Be able to describe how to manage the learning environment.
- **CLO12**: Be able to describe how to demonstrate effective communication skills.
- **CLO13**: Be able to describe how to demonstrate questioning skills and techniques.
- **CLO14**: Be able to describe how to demonstrate effective presentation skills.
- **CLO15**: Be able to describe how to respond appropriately to learners’ needs for clarification or feedback.
