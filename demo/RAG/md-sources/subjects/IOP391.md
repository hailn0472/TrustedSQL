# IOP391 - IoT application development project_Dự án phát triển ứng dụng IoT


## Course Information - IOP391

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: 45h (60 sessions) contact hours + 0.75h final exam + 104.25h self-study
- **Pre-Requisite**: IoT102
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - IOP391
This course is aimed to give you the basics you need to start working with IoT. Students are required to carry out projects in laboratories as assigned by teachers (mentors), through sample tutorials, students can do IoT applications in practice, training students the basic skills of practicing technical professions in the field of control through the Internet to connect things. Group size is limited to 1-2 students, appointed by the faculty (mentor)

### Student Tasks - IOP391
- Register for the programming language to be used C and Arduino software '- Get group allocation and assignment(s) as arranged by the teacher (mentor) '- Select team leader & create a Git environment ( use account @ fpt.edu.vn) '- Split and schedule work with other team members within repeat binding (see Appendix 1) '- Attend at least 80% of exposure slots to accept the final result '- Students are responsible for following the Regulations of the Lab '- Only use student laptops for all practice/study purposes '- Report on work status, present work results according to the provisions of Appendix 1

### Tools - IOP391
• Arduino IDE 1.8.10 or higher • Tinkercad • Web server application: + Blynk cloud server • Electronic devices used in the project (for a group of Students). + 01 Boad ESP8266 NodeMCU Lua CP2102 or (Module Wifi RF Bluetooth ESP32 NodeMCU) + 01 Boad Temperature and humidity sensor DHT11 + 01 Breadboard + Cable 40 male - female 10 cm + 01 Boad I2c + 01 Boad LCD 16x2 + 01 DC5V 3A Power Supply Adapter + 01 Jack DC Female 5.5x2.1 mm DC-017 + 01 Buzzer 3V + 01 Mobile phone

## Course Learning Outcomes (CLOs) - IOP391

- **CLO1**: Use the knowledge learned to solve technical problems related to IoT.
- **CLO2**: Acquire data, examine the methods of infrastructure for boad Arduino and ESP8266.
- **CLO3**: Design, Develop and Analysis
- **CLO4**: Apply project management principles to IoT application development projects
- **CLO5**: Write a professional research report.
- **CLO6**: Practice presentations and communication among team members.
- **CLO7**: Show a professional working attitude
