### Description - DTG102
The course empowers students to master 3 most common Adobe 2D tools for graphic designers, which are Illustrator, Photoshop, and InDesign, so that they can finalize their 2D designs better. Through practical assignments, students get to apply the concepts they've learned in other courses, like: color, typography, shape creation, photograhy, composition and layout etc. by using computers and design tools to create graphic applications. Adobe Illustrator: Turn out professional-looking graphics for web or print with Adobe Illustrator software. Through practical exercises, become fluent in the premier program for line art, logos, vector graphics and quick page layout as well as tricks and time efficient techniques to keep work clean and professional. Adobe Photoshop: Best for editing and enhancing raster images, like photos, with tools for retouching, compositing, and digital painting. Adobe InDesign: Used for designing layouts for print and digital media, such as magazines, brochures, and eBooks, offering precise typography control and layout composition.

## Course Learning Outcomes (CLOs) - DTG102

- **CLO1**: Have basic experience in 2D graphic, vector-based appliction, bitmap-based application and layout application.
- **CLO2**: Use application tools to create graphic design works, logo, characters, editing images, layout.
- **CLO3**: Know how to create typography, color study, and value study works
- **CLO4**: Operate and master vector skills to draw, edit, colorize, making shapes and form.
- **CLO5**: Operate and master bitmap skills to edit photo, collaging, cut and clone, manipulation.
- **CLO6**: Design simple 2D graphic works such as logo, flyer, icon set, poster, small magazine...
- **CLO7**: Having a positive attitude and a professional working style
