### Description - ACD301
This comprehensive Basic Unity Training Program is designed to equip participants with essential skills in Unity game development. Starting from the fundamentals of Unity interface and scripting in C#, the course progresses to cover advanced topics such as physics, animations, and user interface design. Through a combination of lectures, hands-on labs, and real-world projects, participants will gain practical experience and confidence in using Unity for game development.

### Student Tasks - ACD301
- Students must attend more than 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises, assignments and labs given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose

### Tools - ACD301
- Internet - Visual Studio 2019 or later (C# programming language) - Unity software (latest version)

## Course Learning Outcomes (CLOs) - ACD301

- **CLO1**: Understand the Unity interface and basic tools for game development
- **CLO2**: Write and implement C# scripts for game logic and interactions.
- **CLO3**: Create and manipulate game objects, animations, and physics components.
- **CLO4**: Design user interfaces and handle user input effectively.
- **CLO5**: Develop small games and interactive applications using Unity.
- **CLO6**: Troubleshoot and debug common Unity issues.
- **CLO7**: Collaborate effectively in a team environment for game development projects.
