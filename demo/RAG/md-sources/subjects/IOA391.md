### Description - IOA391
In this course, IoT technology will be applied to the implementation of a real project by using the relevant knowledge. The application of IoT technology in the course through information technology research and application issues includes the steps of collection user requirements, data, analysis and implementation of an IoT project in real life. related to the agricultural sector. The implementation steps will include design, implementation, testing and demonstration related to the field of IoT for agriculture.

### Student Tasks - IOA391
- Register the IoT project related to agriculture, - Build the team & select/define the project topic with arrangement/guide from the teacher - Select the team leader and using the FPT account (@fpt.edu.vn account) to setup/configure the project managemernt environment (sources, tasks, issues, milestones) on the GitLab & project documents management on the OneDrive. - Get the detailed assignment from the teacher, plan the project tasks, and execute the project accordingly - Students must attend at least 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises, assignments and labs given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose Student is responsible to do all exercises given by the teacher in class or at home and submit on time - Using the GitLab to collaborate in every phase of the project by all the team members - Promptly access to the FU LMS at https://flm.fpt.edu.vn/ for up-to-date course information

## Course Learning Outcomes (CLOs) - IOA391

- **CLO1**: Know how to use and operate IoT technology systems in agriculture.
- **CLO2**: Exhibit professional working attitudes
- **CLO3**: Apply knowledge of IoT system, its architecture and main components.
- **CLO4**: Build a typical IoT agricultural system, understand the architecture and function
- **CLO5**: Know how to collect and analyze data with IoT for precision agriculture and strategically store and share data for public access
- **CLO6**: Use basic statistical tools that can be used to analyze data collected in agribusiness
- **CLO7**: Apply knowledge related to AI in agriculture to implement a real project.
- **CLO8**: Work efficiently in groups and evaluate the algorithms on real-world problems.
- **CLO9**: Write a professional research report.
- **CLO10**: Practice oral presentation and inter-personal communications.
