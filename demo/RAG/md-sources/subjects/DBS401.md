- **Credits**: 3

### Description - DBS401
This course will introduce the student to the essential best practices in database security strategies. The student will be provided with the tools, techniques and industry accepted methodologies so that upon completion of the course the student will be able to describe key concepts database security and how to apply those concepts to securing database management systems within their orgaization.

## Course Learning Outcomes (CLOs) - DBS401

- **CLO1**: Understand the role of database and information systems security for enterprise and organization
- **CLO2**: Experience the case studies of hacking SQL injection
- **CLO3**: Understand common SQL statements and SQL constructs used to exploit weaknesses
- **CLO4**: Perform SQL injection exploitation and identify defensive strategies against these exploits
- **CLO5**: Understand of database auditing fundamentals
- **CLO6**: Perform the auditing activities that are specific to database security auditing
- **CLO7**: Understand the methodology used to perform a security test
- **CLO8**: Understand the remediation
- **CLO9**: Understand Security Architecture and plan defines steps to reinstate a network after a disaster occurs
- **CLO10**: Understand the steps of administrator must take into account prior to installation of a database Secure the installation and configuration of various database management systems
- **CLO11**: Understand the different database management system models and applications and describe the architecture of Oracle, MySQL, and Microsoft SQL Server
- **CLO12**: Understanding Secure the installation and configuration of MySQL server
- **CLO13**: Understanding Secure the installation and configuration of Microsoft SQL server
- **CLO14**: Understanding Secure the installation and configuration of Oracle
- **CLO15**: Understanding Password, Profiles, Privileges, and Roles with SQL Server, MySQL, and Oracle
- **CLO16**: Discover locate SQL vulnerabilities
