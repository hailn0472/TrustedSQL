# eat201 - Đánh giá và kiểm tra - Assessment and Testing


## Course Information - eat201

- **Credits**: 3
- **Time Allocation**: Contact time: 30 sessions; 1 session = 90'
- **Pre-Requisite**: ETL101
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - eat201
Objective: 'This course aims to equip students with an insight into the important inssues of language testing and skills to design questions for language achievement tests of multiple language skills." Teaching method: lecture + acitivities + project works

### Student Tasks - eat201
<- Students must attend more than 80% of contact slots in order to be accepted to the final examination. - Student is responsible to do all exercises, and assignments given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access to the FU CMS at http://cms.fpt.edu.vn for up-to-date course information>

### Tools - eat201
textbook + reference materials

## Course Learning Outcomes (CLOs) - eat201

- **CLO1**: Identify different types of language tests and their purposes
- **CLO2**: Weigh the roles of testing in an EFL course
- **CLO3**: Evaluate the validity and reliability of a language test based on clear criteria
- **CLO4**: Construct the specifications for developing a specific test of an EFL course
- **CLO5**: Design an achievement test for a specific EFL course
- **CLO6**: Evaluate the beneficial backwash of a test

## Materials - eat201

### Main Materials
- **Testing for Language Teachers** | Author: Arthur Hughes | Publisher: Cambridge University Press | ISBN: 521484952

## Assessment - eat201

### Assignment
- Weight: 20.0%
- Completion Criteria: >0
- CLO: LO1, LO2, LO4
- Question Type: Write the specifications of a specific EFL achievement test (content, structure, timing, medium, techniques, scoring)
- Note: Group work (3 people/ a group) with a clear task delegation

### Presentation
- Weight: 30.0%
- Completion Criteria: >0
- CLO: LO1, LO2, LO3
- Question Type: A presentation to evaluate the validity and reliability of a specific test based on the textbook's criteria
- Note: Group work (4 people/ a group) with a clear task delegation

### Project 1
- Weight: 30.0%
- Completion Criteria: >0
- CLO: LO1, LO2, LO3, LO5, LO6
- Question Type: Construct a listening/ reading achievement test for a specific EFL course
- Note: Group work (3 people/ a group) with a clear task delegation

### Project 2
- Weight: 20.0%
- Completion Criteria: >0
- CLO: LO1, LO2, LO3, LO5, LO6
- Question Type: Construct an oral/ writing test for a specific EFL course
- Note: Group work (3 people/ a group) with a clear task delegation
