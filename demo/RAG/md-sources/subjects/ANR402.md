## Course Information - ANR402

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h)
= 45h contact hours + 105h self-study
- **Pre-Requisite**: None
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - ANR402
1. The aim of this module is to facilitate students’ understanding of the fundamental concepts, principles and techniques of 3D animation and snapping bones and create controls for the character 2. You will build the skeletal system and control system for the character.

### Student Tasks - ANR402
'- Attend at least 80% of contact hours in order to be accepted to the final examination - Actively participate in class activities - Fulfill tasks given by instructor after class - Use their own laptop in class only for learning purpose - Read the textbook in advance - Access the course website (https://flm.fpt.edu.vn) for up-to-date information and material of the course

## Course Learning Outcomes (CLOs) - ANR402

- **CLO1**: Know how to analyze an simple rig
- **CLO2**: Rig a whole character using Advanced Skeleton
- **CLO3**: Have a proficient in presentation and teamworks.
- **CLO4**: Know how to rig a helicopter , or a bicycle.
- **CLO5**: Know how to rig a bouncing ball.
- **CLO6**: Build a biped rig and finish the skeleton with beaver
- **CLO7**: Weight Painting with character (for the biped rig from lesson 4)
- **CLO8**: Create facial rigging and finish the rig from lesson 4 and 5
- **CLO9**: Create constrain a character an objects, object with both the hands ...
- **CLO10**: Create simple hair and clothes for the character
- **CLO11**: Do character skinning and complete a character rig.
