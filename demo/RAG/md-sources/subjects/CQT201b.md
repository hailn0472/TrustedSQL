- **Credits**: 3
- **Degree Level**: Bachelor

- 30 online sessions (1 session = 90 minutes)
- 1 final exam includes Theoretical Exam (60 minutes) and Practical Exam (120 minutes)

- **Min Avg Mark To Pass**: 5

### Description - CQT201b
The course is aim to equip learners to create convenient, fine user interface on auto. Qt is a popular framework to develop UI software application on automotive sysem. The student will learn about Principles of Qt framework; Techniques, tools and skills essentials to build UI with QML; Techniques to link UI in QML with functional logics in C++; How to use Qt framework for techniques in programming like Multithread, multi languages

### Student Tasks - CQT201b
- Students should self-study all lessons on LMS in time - Pass all conditions before taking final exam in campus
