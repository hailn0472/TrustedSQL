# PRN231 - Building Cross-Platform Back-End Application With .NET_Xây dựng ứng dụng back-end với With .NET


## Course Information - PRN231

- **Credits**: 3
- **Degree Level**: Bachelor
- **Time Allocation**: Study hour (150h) = 49.5h contact hours + 1h final exam + 85' practical exam + 99.5h self-study
- **Pre-Requisite**: PRN221 ( BUILDING CROSS-PLATFORM WEB APPLICATION WITH .NET )
- **Min Avg Mark To Pass**: 5
- **Scoring Scale**: 10

### Description - PRN231
Upon completion of this course students shoud: 1. Understand the followings: • Apply C# language for develop ASP.NET WEB API ( RESTful Service applications ) • Fundamental concepts of .NET Core Platform • Basic knowledge of ASP.NET WEB API on .NET Core • Basic knowledge of RESTful Service and Microservice architecture 2. Be able to: • Develop Cross - platform Back-end application can be used by Desktop or Web applications (Cross - platform) • Develop RESTful Service applications by ASP.NET Web API and Windows Communication Foundation (WCF) • Implement security in the ASP.NET WEB API • Implement sending Ajax request to ASP.NET WEB API • Implement security JWT in ASP.NET Core Web API • Develop Distributed applications based on Microservice architecture 3. Be able to work in team and present group's results

### Student Tasks - PRN231
- Students must attend at least 80% of contact sessions in order to be accepted to the final examination. - Student is responsible to do all assigned exercises given by instructor in class or at home and submit on time - Use laptop in class only for learning purpose - Promptly access https://flm.fpt.edu.vn/ for up-to-date course information

### Tools - PRN231
- Internet - Visual Studio.NET 2019 version 16.8.3 or later - Platform : .NET 5.0 or later

## Course Learning Outcomes (CLOs) - PRN231

- **CLO1**: Describe about .NET Core Platform, and ASP.NET WEB API Architecture
- **CLO2**: Demonstrate Models, ODATA, Entity Framework Core ,and Media Formatters & Content Negotiation
- **CLO3**: Demonstrate about and Binding, Validation & Routing and sending AJAX Requests to ASP.NET Web API
- **CLO4**: Demonstrate about implementing security in RESTful WebService, implementing RESTful Services by WCF, gRPC Services and introduction about Microservices architecture.
