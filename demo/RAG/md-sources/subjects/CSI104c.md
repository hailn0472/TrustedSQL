### Description - CSI104c
This course provides an overview of computer Fundamentals. Topics cover all areas of computer science in breadth such as computer organization, network, operating system, data structure , file structure, social and ethical issues.

### Student Tasks - CSI104c
Students complete the online course MOOC and get certification for MOOC to be allowed to take Final Exam

### Tools - CSI104c
- Internet

## Course Learning Outcomes (CLOs) - CSI104c

- **CLO1**: List the subsystems of a computer and describe the role of these components
- **CLO2**: Distinguish between text file and binary file and access methods
- **CLO3**: Describe and explain operations within a relational database
- **CLO4**: Descibe security goals and discuss ethical issues
- **CLO5**: Convert a number from one base to other base( decimal, binary, octal and hexadecimal)
- **CLO6**: Describe how different data type is stored inside a computer as bit patterns and operations on data
- **CLO7**: List the layers in netwoking and their relationship
- **CLO8**: Undestand the role of OS in a computer system
- **CLO9**: Define a algorithm and describe tools used to develop algorithms
- **CLO10**: Explain how a program in a high-level language is translated into machine language
- **CLO11**: Describe the software lifecycle
- **CLO12**: Discuss some data structures: Array, Records, Linked list
